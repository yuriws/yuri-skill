# 每批一致性校验与体检

按本批实际范围完成检查，标明未执行、未覆盖或待复核项目。**机械通过、候选已判、语义与文学效果复核是三件事**；某个词表零命中不代表全部通过。具体判据见[rules.md](rules.md)。

## 一、确定性检查

- [ ] 本批章号唯一、升序、区间连续且归卷正确，每100章一卷；章标题和章末分隔完整，追加前后无正文丢失、重复或悬空。
- [ ] 正文仍以卷文件为唯一真相源；生成整合稿前无未处理的单章／卷混合来源，未手改生成物。
- [ ] UTF-8与项目约定的换行、缩进、尾随空格和末尾空行一致；CRLF或全角缩进不是所有项目的通用错误，按本书输出约定判断。
- [ ] 已定改名与改称谓的有效旧项残留已处理，相关回溯范围已登记。专名包含关系或合法引用不能见词即改。
- [ ] 外形事实、术语、关系、首次交代位置与设定表一致；反复出现的保留男性已标“男·用他”。
- [ ] A—E改动已归类，B类去糙单列；**仅C类新增关系／性别互动张力每章≤3处**且供用户复核；不限制所有新增句，不拿B／E绕过C。
- [ ] 超性转的校对、主动改梗等已标“可回退”。
- [ ] 新规则在入口索引与相关清单可见；改skill自身后运行`python scripts/verify.py`核ID集合及重复、护栏文本、模板与链接。该脚本不扫描小说正文质量。

## 二、候选扫描后逐项判断

候选检索只帮助定位，未命中不能保证不存在。无现成脚本时按以下方法检索复核，不声称已经自动化。

- [ ] **按人扫称呼／代词**（4.6／4.32／4.33）：先定位女性角色名及明确指代，扩读附近称谓；约12字可作初始窗口，不作覆盖保证。跨句、对话省略与裸称谓另查；“哥／哥哥”等长短形式都考虑。
- [ ] 排除亲属关系“她哥哥”、专名“兄弟会”、指他人及“费了老大劲”等程度用法；“老大”可称女性，称呼修复保亲疏与权力关系。
- [ ] “他／她”逐处确认被指对象；保留男性及合法泛指不误改。多个“她”确有歧义时用姓名／称谓消歧，复数按4.34及项目口径。
- [ ] **性别论述候选**（4.35b／4.35e）：可检索性别群体词附近的成词评价谓词，再读完整上下文，识别偏见、反讽、转述与批判；近距窗口不覆盖跨句和换说法，不自动删改。
- [ ] **身体词与重复词只提示**：不凭出现身体部位判违规，不凭词频计女码得分；近距重复先判功能、节奏和有意呼应，不用同义替换伪装改进。

## 三、语义与文学效果复核

- [ ] 通读本批，确认件数／装备／身体行为／比喻在已定世界与人物条件下成立（4.9）；不因主角女性化自动削弱其能力或去掉合理的战斗、接触与冲突。
- [ ] 性别前提、配角关系、分工和第三方理由在性转后成立（4.35家族）；修复因果而不凭空改人物内核。
- [ ] 主角内心、台词与旁白未机械继承失效的原男主性别立场；有意保留的人物缺点与作者认同的偏见分开判断，不因主语是女性自动整句删（4.35e）。
- [ ] 改写未新增“女性必然争风、嫉妒、互拆台”等归因；保留合理人物缺点与复杂冲突，不强制所有对手正当或所有冲突利益化（4.35e）。
- [ ] 去糙按说话人完成，表达功能未削弱；改台词后配套“爆粗口”等叙述同步。允许自然重复，不为禁止同词而机械轮换。
- [ ] 服装和女性外貌措辞符合个人版已确认偏好；行动、职业与场景功能仍成立（4.41／4.43）。
- [ ] 连续阅读能感知具体女性人物，外貌、身形、气质、声音、语气、动作、内心与互动均可按需使用；允许直接形容、通用词和中性动作。七维不按比例打卡，不强求每句女性专属或场景唯一。
- [ ] 形象描写与当前情境、原文文风和节奏协调；优先将现有抽象处写准，需要新增时自然嵌入，不凑固定次数或动作库。
- [ ] 欣赏、吸引和物化按完整语境区分（4.4／4.5）；不因同性吸引或身体词直接删改。无露骨、性征尺寸看点或扫描式部位罗列，现有硬护栏全部满足（4.10）。
- [ ] 去凝视或删无效配对猜测后，剧情功能、母题与后续必要信息仍在（4.39／4.44）；没有信息缺口就不硬补等量暧昧。
- [ ] 感情表达符合本书已定方向与各人认知；自知、双方知情、关系确认、对外公开分别判断；旁人可合理猜测但未获得作者上帝视角（4.45）。
- [ ] 恋爱与友情可区分；不把帮助、贴近、欣赏一律升级成恋爱，也不因同为女性压掉已定吸引。内敛或直白按人设，不统一禁止内心解释、心动或吃醋。
- [ ] 多人同场仍有不同性格与说话方式；无为改文自证的解释句、机械微动作或AI黑话；正文破折号按现有文风要求处理（4.0／4.38）。

## 四、设定、版本与存量

- [ ] 新条目区分用户明确要求、文本一致性约束与待验证建议；不会影响后续写法的情节流水移批注，不固化为新设定。
- [ ] 非状态类时间／数量与正文相符；等级、装备、技能一般不抄第二处，只有真实剧情约束记设定（[structure.md](structure.md)）。
- [ ] 新语义规则或判据改变已评估存量影响，登记章节范围、已复核／已修改／待处理；仅调整索引措辞不自动全书重审。更新skill不等于项目与旧稿已更新。
- [ ] 常驻引用实际存在且目标含对应内容；项目记忆只留进度／文件指针。膨胀线按去空白字符数测量，连续两批超线再下沉。
- [ ] 体检入口与模板在本文件，只有需要分层／建容器时再查structure；不为次数指标省略必要查证，也不自动新增速查或审计文件。
- [ ] 本批体检文件真实落盘，检查范围、膨胀判断与待办可追溯。
