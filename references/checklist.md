# 每批一致性校验与体检

按本批实际范围完成检查，标明未执行、未覆盖或待复核项目。**机械通过、候选已判、语义与文学效果复核是三件事**；某个词表零命中不代表全部通过。具体判据见[rules.md](rules.md)。

## 一、确定性检查

- [ ] 已按项目正文载体核对权威来源、章节顺序、区间和完整性，写入位置准确，无丢失、重复或悬空；采用默认卷文件时每100章一卷并核归卷，其他已定载体用相应方法核验。
- [ ] 正文权威来源明确；默认卷文件为真相源，整合稿为生成物。使用脚本前核其适用格式及来源，无未处理的混合来源；覆盖／清理来源前确认可恢复备份，归档未被当成推送授权。
- [ ] UTF-8与项目约定的换行、缩进、尾随空格和末尾空行一致；CRLF或全角缩进不是所有项目的通用错误，按本书输出约定判断。
- [ ] 已定改名与改称谓的有效旧项残留已处理，相关回溯范围已登记。专名包含关系或合法引用不能见词即改。
- [ ] 所有题材首次提及时自然明确已定性别，真正登场按角色重要性建立形象；原文无创建流程也未漏掉性别确立。外形、术语、关系与设定一致，反复出现的保留男性标“男·用他”。
- [ ] A—E改动已归类，B类去糙单列；**仅C类新增关系／性别互动张力每章≤3处**且供用户复核；不限制所有新增句，不拿B／E绕过C。
- [ ] 改动按目的分类；必要去糙及语境修复归B，额外校对／主动改名改梗等超范围干预标“可回退”，未把所有保梗处理一律判为超范围（4.37）。
- [ ] 新规则在入口索引与相关清单可见；改skill自身后运行`python scripts/verify.py`核ID集合及重复、护栏文本、模板与链接。该脚本不扫描小说正文质量。

## 二、候选扫描后逐项判断

候选检索只帮助定位，未命中不能保证不存在。示例、关键词、相邻窗口和重复次数均不构成语义检查的适用门槛；先按通用目标通读，再决定保留或修改。角色处置、事实依据、用户已定方向、内容边界与工具支持格式等真实约束保留。无现成脚本时按以下方法检索复核，不声称已经自动化。

- [ ] **按人扫称呼／代词**（4.6／4.32／4.33）：先定位女性角色名及明确指代，扩读附近称谓；约12字可作初始窗口，不作覆盖保证。跨句、对话省略与裸称谓另查；“哥／哥哥”等长短形式都考虑。
- [ ] 排除亲属关系“她哥哥”、专名“兄弟会”、指他人及“费了老大劲”等程度用法；“老大”可称女性，称呼修复保亲疏与权力关系。
- [ ] “他／她／他本人”等逐处确认实际所指及群体范围，不按固定句式豁免；保留男性及合法泛指不误改，“他人／其他”等词内用字不作残留。多个“她”确有歧义时用姓名／称谓消歧，复数按4.34及项目口径。
- [ ] **性别论述与群体对照候选**（4.35b／4.35e）：可检索性别群体词、其他人及就连／只有等对照附近的表达，逐处核改后所指、评价者与比较对象，再辨偏见、反讽、转述及批判；无群体词也可能有固定强弱分配，近距窗口不覆盖跨句和换说法，不自动删改。
- [ ] **身体词与重复词只提示**：不凭出现身体部位判违规，不凭词频计女码得分；近距重复先判功能、节奏和有意呼应，不用同义替换伪装改进。

## 三、语义与文学效果复核

- [ ] 通读本批，主动复核原性别牵动的穿戴用品、数量尺度、身份关系、动作接触、生活安排及社会待遇（4.9），不限于列举题材或关键词；改后相关数量、动作、因果及后续引用一致，未漏掉隐含依赖，也未仅凭女性身份造新物品或削弱能力。
- [ ] 性别前提、比较评价、资格、各类人际关系、分工与第三方理由分别核改后逻辑、世界设定、表达归属与叙述立场（4.35家族），覆盖跨句、跨段及隐含理由，不限交友或与男性比较；不凭字面成立直接放行，也不把既定制度或人物有意偏见一律删掉。
- [ ] 群体称呼及就连／只有等比较符合改后实际人物范围；没有按原女性名单把同场性转角色排除在女性之外（4.35b）。
- [ ] 通读整场及实际覆盖的相邻章，检查风险察觉、判断／决策、行动、求助与受照应的分配；未保留「原女性持续失去主体性、性转角色包揽优势」的框架，不能只删词或改名字就判通过（4.35b）。
- [ ] 必要时已双向调整反应、台词功能或互助顺序，有人物及情境依据，保住关键情节、机制／结果、能力和人物内核；合理恐惧与经验差异仍在，无全员同反应、每人露怯或两组强弱配额，也未用正文说教代替修改（4.35b／4.41）。
- [ ] 主角内心、台词与旁白未机械继承失效的原男主性别立场；有意保留的人物缺点与作者认同的偏见分开判断，不因主语是女性自动整句删（4.35e）。
- [ ] 改写未新增“女性必然争风、嫉妒、互拆台”等归因；保留合理人物缺点与复杂冲突，不强制所有对手正当或所有冲突利益化（4.35e）。
- [ ] 主角及所有已性转人物按表达归属去糙，含对白／内心，同伴或反派等身份不豁免；其他人物按本书要求处理。情绪、威慑与笑点保住，配套“爆粗口”等叙述同步，允许自然重复（4.31）。
- [ ] 各场景穿戴均按事实与方向复核，正式装偏好继续执行；换装后款式、件数、配件、穿脱／遮挡及后续动作引用一致，未只换名称（4.9／4.43）。女性外貌措辞合偏好，形象变化有既定原因与时间尺度；不强制渐进、镜子或旁人反应（4.8／4.41）。
- [ ] 连续阅读能感知具体女性人物，外貌、身形、气质、声音、语气、动作、内心与互动均可按需使用；允许直接形容、通用词和中性动作。七维不按比例打卡，不强求每句女性专属或场景唯一。
- [ ] 已独立于原文纠错、群像纠偏与恋爱推进，主动检查主要性转角色在本批连续阅读中的具体形象；不足处按已定形象改写或自然补写，独处与战斗同样纳入判断。不是仅因代词正确、去糙完成、原句无错或只需L1就判形象达标（4.41）。
- [ ] 形象描写与当前情境、原文文风和节奏协调；形象已足够或当前为紧张／系统段时可不新增，但要有实际描写与效果依据，不凑次数、段落数或动作库。
- [ ] 形象补足按完整场景／必要前文选点，已说明具体形象缺口及补后建立／延续的可感印象；仅增加通用动作、性格解释或笑料不单独算补足成功。不是每个功能短句都要加，也不因已有一个形容词或脸红就自动通过；新增动作如实登记，原有信息及场景事实保住（4.41①）。
- [ ] 欣赏、吸引和物化按完整语境区分（4.4／4.5）；不因同性吸引或身体词直接删改。无露骨、性征尺寸看点或扫描式部位罗列，现有硬护栏全部满足（4.10）。
- [ ] 去凝视或删无效配对猜测后，剧情功能、母题与后续必要信息仍在（4.39／4.44）；没有信息缺口就不硬补等量暧昧。
- [ ] 感情表达符合本书已定方向与各人认知；自知、双方知情、关系确认、对外公开分别判断；旁人可合理猜测但未获得作者上帝视角（4.45）。
- [ ] 恋爱与友情可区分；不把帮助、贴近、欣赏一律升级成恋爱，也不因同为女性压掉已定吸引。内敛或直白按人设，不统一禁止内心解释、心动或吃醋。
- [ ] 多人同场仍有不同性格与说话方式；无为改文自证的解释句、机械微动作或AI黑话。自证按4.38的目的与实际作用判断，正常身份、形象、心理、关系描写不因删后仍可看懂情节而被误删。修复深度按实际问题选择，不按档位自动扩大；正文破折号按现有文风要求处理（4.0）。

## 四、设定、版本与存量

- [ ] 新条目区分用户明确要求、文本一致性约束与待验证建议；不会影响后续写法的情节流水移批注，不固化为新设定。
- [ ] 非状态类时间／数量与正文相符；等级、装备、技能一般不抄第二处，只有真实剧情约束记设定（[structure.md](structure.md)）。
- [ ] 新语义规则或判据改变已评估存量影响，登记章节范围、已复核／已修改／待处理；仅调整索引措辞不自动全书重审。更新skill不等于项目与旧稿已更新。
- [ ] 角色归档仍可查所有影响后文的已定事实，包括外貌／声线及身份或关系约束，不为30—50字目标丢内容；导航卡精简不等于权威设定删减。常驻引用目标有效，版本和必要镜像同步；膨胀线按去空白字符数测量，连续两批超线再下沉。
- [ ] 通用模板在本文件；既有项目沿用已定维护入口，并同步必填记录项。只有需要分层／建容器时再查structure，不自动新增速查或审计文件。
- [ ] 本批体检文件真实落盘；女性形象与补写效果、候选处理结果、未检查范围分别有记录，附必要位置与依据，不用改动清单或脚本退出码替代效果复核。
