# 基础文件：骨架、格式与创建时机

`SKILL.md` 第 0 步的执行细则。**改第 1 章前读一次**，之后按需回查。

## 创建顺序是单向依赖，不可跳步

```
feasibility.md（决策）→ GLOSSARY.md（设定表）→ RULES.md（规则库）
```

`CAST.md` / `MAINTENANCE.md` 是**后期按需拆出**的，不是一开始就建。

| 文件 | 何时创建 | 格式要点 |
|---|---|---|
| `feasibility.md` | **改第 1 章前**，用户逐项拍板后 | §0 决策总表：改造幅度 / 主角名 / 谁女性化 / 尺度 / 结局。**只记定案，不记论证** |
| `GLOSSARY.md` | 同上，**与决策同步** | 角色处置表（原名 / 新名 / **性别** / 处置 / 性格 / **称呼映射**）＋ 人物进度 ＋ 待核查。条目 ≈80 字/行 |
| `RULES.md` | 从设定表提炼，**边改边补**（每章沉淀 2–4 条） | 编号规则表：`0.x` 硬护栏 / `1.x` 角色 / `2` 称呼替换 / `3` 描写 / `4.x` 隐性错误 ＋ **长尾索引**（触发词 → 规则号 → 一句话要点） |
| `CAST.md` | 角色表涨到「每轮读着累」时拆出 | **准入＝「性别 ＋ 称呼」＋ ≤12 字身份**；背景 / 进度 / 论证一律下沉 `GLOSSARY`。**角色 30 章未提及 → 删行** |
| `MAINTENANCE.md` | 批尾步骤散在长尾层里读着累时拆出 | 批尾校验清单 ＋ 体检步骤。**必须一次通读跑完，不再往别处散**。观察线 3,000（内容部分） |
| `notes/batch-NN.md` | **每 10 章（批尾）** | 固定模板见下 |
| `text/vol-00N.md` | 每 100 章一卷 | 章标题 `## 第NN章《标题》`；改文**追加到文件末尾** |

## 目录骨架

```
<项目根>/
  text/vol-00N.md      ← ★ 正文真相源（每 100 章一卷），可直接编辑
  RULES.md             ← 规则库**核心层**（只放改文随手要用的规范）
  RULES-DETAIL.md      ← 规则库**长尾层**（按需 grep）：工作方式、校验清单、背景长规则
  CAST.md              ← **人物速查卡**—— 准入＝性别 + 称呼，其余不进
  MAINTENANCE.md       ← **批尾操作手册**（批首/批尾读一次，不在每轮必读）
  notes/batch-NN.md    ← 每 10 章一份批尾体检
  feasibility.md       ← 决策记录（改造方向与边界）
  GLOSSARY.md          ← 设定表**动态层**（角色与处置 + 人物进度 + 待核查）—— 不每轮读，按需 grep
  GLOSSARY-STATIC.md   ← 设定表**静态层**（作品事实 / 术语 / 主角设定 / 关系网 / 结局 / 校验口径）
```

**可以砍掉的两样**（实测都没建，价值被 §4 的规则＋反例取代）：

- **滚动摘要**：直写卷文件后，靠 grep 卷里的章标题即可定位。若项目保留单章文件，见 [`structure.md`](structure.md) §5.1。
- **前 3 章范本**：规则＋反例已经承担了这个作用。

**现行归档流程**：改文 → 追加进 `text/vol-001.md` → 每章一次 commit。卷文件是唯一真相源，改文一律改它，**不要改整合稿**（整合稿由脚本从卷重建）。

**注意目录树本身也会过期**——曾出现「目录树里列着一个早已删除的文件」。批尾顺手核一遍引用是否还存在。

## 项目记忆：只留一行指针

平台有项目级记忆机制时，**不要把设定搬进去**——它每轮注入、只增不减，早晚挤爆。

**平台无关的等价要求**：在项目记忆 / 常驻上下文中保留**一行指针**，指向设定表与规则库的路径。目的只有一个——**换会话时第一件事就能找到它们，而不是靠猜。**

## 批尾体检 `notes/batch-NN.md` 固定模板

直接抄：

```
# 第 N 批批尾体检（0XX–0YY）· 轻量版
- 区间：第 0XX–0YY 章，共 10 章，每章单独提交
- 字数口径：去空白字符数（禁裸 wc -m）

## 膨胀判断（实测）
| 文件 | 实测 | 预警线 | 判定 |        ← 逐项标 ✅/⚠️，越线即整条下沉

## 语义体检
- 全卷「旧名」= 0；本批破折号 = 0；性别处置逐章核过……

## 待办 / 非阻塞
```

> **两条实测提醒**：
> ① **批尾体检必须真的建文件**，不能只用脚本抽查代替——实测漏建过一次，被用户问出来才补。
> ② **模板要能一次通读**，体检时才不会来回翻。

## 脚本

`scripts/build-merged.py`（随 skill 附带，拷进项目根即可）：

- `python build-merged.py` —— 把 `text/` 下的正文拼成**整合稿** `text/merged-*.md`（生成物，`.gitignore` 排除）。
- `python build-merged.py --archive` —— 把单章按卷追加进 `text/vol-00N.md`（追加 + **按章节标题去重**，重复执行不会写两遍）。

**安全顺序（写死在流程里，不要跳步）**：commit → push → 确认远程同步 → 才跑 `--archive` → 确认卷文件完整 → 才删单章 → 再提交。归档后单章被删除，恢复靠 Git 历史；**未推送的历史只在本机，丢了就没了**。
