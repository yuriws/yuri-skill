# 踩过的坑 · 尚未验证

历史踩坑清单（写 skill / 开工时的注意事项）＋ 哪些做法已验证、哪些还是空白。

## 踩过的坑

1. **长 Markdown 落盘后必须读回来验证**——曾在大文件生成时串入 5 处英文 / 拼音残片，同一代词连续改错两次。不能凭生成记忆判断。
2. **各章文件的内部小节编号可能不一致**（第 1 章正文是「一、」，第 2/3 章是「二、」）。按固定索引抽取会抽错，要按**节名**定位。
3. **Git Bash 的 heredoc 传含中文的脚本会被错误解码**——需 `PYTHONIOENCODING=utf-8 PYTHONUTF8=1`。
4. **Windows 下 Python 写 `/tmp` 会解析成当前盘符根而失败**——须用 `tempfile.gettempdir()`。
5. **长对话需保存接续信息**——每批先落盘进度、实际检查范围与待办；是否换会话按上下文长度及用户安排。换会话时重新定位现行规则和相关设定，不把每10章开新会话当硬要求。
6. **笔记里的位置指针要记「章号 + 引文片段」，不要记行号**——归档删单章后行号失效，引文仍可定位（此设计当初是无意的，后来救了场）。
7. **跨题材隐含依赖不能只靠代词检索**：穿戴、数量、身份关系、动作与生活安排等，可能依赖原性别却无固定触发词，须通读按rules 4.9核对。已有游戏规则明确女性初始装为内衣＋内裤时，相关剩余数量须联动；若其他场景已定仅一件内衬，不能因女性身份加件。例子展示条件，不限定检查范围。
8. **保存、同步与发布分开**：已授权远程操作的失败按实际连接及仓库状态判断；历史重试经验不自动授权推送或反复尝试。无远程项目可核验本地整理，不以Git工作流替代所有载体的保存方法。
9. **历史工具行为不等于所有平台的规则**：曾有云文档覆盖接口忽略标题参数。已授权上传时，按当前接口核正文、标题及读者可见信息，必要时再重命名，不预设每个平台都要调用两次。面向读者的产物检查内部路径与维护术语；该经验不构成上传授权。
10. **清理来源前核完整性与可恢复备份**：章节及内容完整核验后，确认独立可恢复的本地或已授权远程备份，再按明确范围清理；保留源文件的归档不与删除唯一副本混为一步。
11. **追加新章前先 grep 关键短语，确认是全新章并定位到真实末尾**——曾在追加时顺手修上一章的过渡句，结果这句被挤到文件末尾造成悬空。
12. **避免旧缓存覆盖与编码污染**：写回前核当前内容与定位锚点，选择能保留正文的编辑方式，大文件脚本是可选工具。写后复核完整性、换行及意外实体转义；实体与编码残片只是候选，按其是否改变原意或妨碍检索处理，不一律要求所有HTML实体清零。
13. **通配匹配要精确**：`glob("vol-*.md")` 会把摘录件 `vol-002-ch021-030.md` 当成正文卷，导致同一批被拼两遍、虚报 40 章（正确 30 章）→ 改用逐字符全匹配。**这是会污染正文的真 bug，不是显示问题。**
14. **否定式过时状态最危险**：「终结技尚未获得」「某角色尚未出场」读着对，实际早已变化，会持续误导后续判断。**查到事实变化就立刻改，不要留着「尚未」二字。**
15. **事实写错比漏改更隐蔽**：设定表写「主角 6 级」实为 5 级（6 级是同伴）——属「同一事实两处写」的又一例。**凡事实，只写一处。**
16. **不要把情节层面的做法钉成硬约束**：曾把一次分装备对话提炼成「以后一律按贡献 + 需求」写进设定表，被判不该钉死。判据：**进设定表前问「这条会改变我后面还没写的章节的写法吗？」** 不会 → 别写进去。
17. **AI 的理由可以是错的，要能被推翻**：曾断言「BOSS 等级原文一般不会出问题」，真因是「记数值的目的（交叉核对）已被取消」，且反例确实存在。**给结论时要给出可检验的判据，别给直觉。**
18. **通用 skill 里不许出现单本书的章号 / 角色名 / 台词**——写规则时很容易把来源项目当例子搬进来（「某章某人说『某某』」），下一代换书用时全是噪音，还会被误当成本书设定。**案例只留桥段类型**（「朋友嘲主角活该单身一辈子」＝套路名，可留；带书名、章号、角色名的具体情节 → 留在项目侧规则文件）。**判据：把这段文字给一个没读过那本书的人看，他需要额外信息才能理解吗？需要 → 改写。**
19. **女性化写描写的头号 AI 味：把「感知动作」量化成毫米**——「目光先移开半寸，才重新看回去」「视线偏开一寸」这类句子，看起来细腻，实际是把「被注视的自觉」这种心理写成了位移数据，读起来又绕又假（实测用户一眼指出「非常 AI、不通顺」）。**通顺五症，写完逐句过**：① 精确量化感知动作（毫米 / 角度 / 时长）② 同义反复（「神色照旧没什么波澜」＝照旧＋没什么波澜）③ 双「才」链（「才…才…」）④ 被动绕句（「目光被那道声音吸引了过去」）⑤ 逻辑矛盾（点头，却说「我没在看」）。**改法按实际问题选择**：视线或心理可直接写自然反应，也可直接呈现已定形象；有观察者时才写她察觉被看，不能把这次修法推广成所有女性描写必须有他人注视。空间／时长数据确有动作或机制意义时可保留，普通量化不是自动错误。
