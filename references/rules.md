## 4.0 总纲：语境前提失效——4.x 全家的母问题（**先读这一节**）

**一句话**：性转不是替换代词，是**换一个叙事视角**。原文大量场景、笑点、描写、动机之所以成立，前提是「叙述者和主角都是男性」。这个前提一撤，受影响的**不是词，是整段的因果**。

**七种形态**（细则各自独立，此处只做索引——**它们经常同时出现在一段里**）：

| 形态 | 表现 | 细则 | 档位 |
|---|---|---|---|
| **男性凝视** | 描写 / 评点女性身体，动机是"想看" | 4.4 | L1 / L2 / L3 |
| **性暗示场景** | 低俗笑点的支点是男性的性兴趣 | 4.4b | 主 L3 |
| **刻板印象** | 女性=情绪化 / 花瓶 / 爱八卦，男性=该担当 | 4.35b 归因型刻板 | L2 / L3 |
| **性别前提句** | 字面代词全对，逻辑前提是"主角是男的"；**含以主角性别为轴的对照项与第三方理由**（「哪有女生拉着男生…」「因为有男生在场」） | 4.35 / 4.35d | 主 L1 / L2 |
| **性别隔离框架** | 拿别的女性当背景板反衬男主 | 4.35b | L3 |
| **关系因果** | 配角设定在解释"为何和男主是朋友" | 4.35c | L2 / L3（无 L1） |
| **身体词 / 双关** | 男频梗在女女语境下变成性暗示 | 4.36 | L1 |

**「档位」＝这条通常要动到哪一层。** 标「主 L3」不是"只能 L3"，而是"词级改不动、必须重写场景"。**档位标记的用处**：某条只有单一档位，说明它不用再拆；三档都有的（如男性凝视），才值得在正文里分三小段写。

**这份清单是开放的，不是穷举。** 4.x 每新增一条，先判它属于哪一种形态、挂到本表；**挂不上去说明是新形态，就在表里加一行**——表本身要随实测长。

### 粒度：先判病灶在哪一层，再决定改多少

**两个维度不能互相替代**：**形态**决定「往哪个方向改」，**粒度**决定「改多深」。同样是 L3（整段重组），凝视是「把笔收回主角的反应」、性暗示是「换支点」、关系因果是「补例外」——**方向完全不同**；反过来，同为凝视，L1 删一个词、L3 重写一段，剂量差十倍。

**判错层，改多少都没用。**

| 档 | 病灶位置 | 通用手法 |
|---|---|---|
| **L1 词级** | 只在称呼 / 身份 / 身体词上 | **换词** |
| **L2 句级** | **句子的动机**建立在性别上 | **换动机**、保句式、改角度 |
| **L3 语境级** | **整段场景的驱动力**建立在性别上 | **换支点**、重组语言、转移焦点 |

**手法是跨形态共享的。**「换支点」不专属性暗示——凝视、关系因果、刻板印象在做 L3 时都会用它。所以**细则条目只写该形态独有的陷阱与判定，通用手法不重复写**。

### 判据（改完必做）

**把这一段当成一个全新的场景重读**，问「读者会不会停下来问『为什么』？」

- 不会 → 改对了，进下一句。
- 会（「她为什么要去？」「她为什么在意这个？」「她俩怎么会是朋友？」）→ **病灶在更上面一层，升一档重做**。

**一段里多种形态并存时**（既有男凝又有低俗笑点），按**最上面那一层的粒度**处理，不逐句打补丁。

> **不是「改得少」有问题，是「改成哪一层」有问题。** skill 要的是「改动最小」，不是「粒度最浅」——**最小＝恰好够的那一层**。别因为怕改多就不敢升档；反过来，病灶确实在词上就别硬升档，那是过度改写。两个方向各一个实测：3 字到位的见 4.35，改 40 字仍不够的见 4.4b。

### 防膨胀：细则该写什么

写细则时一旦开始写「怎么改」，先问一句：**这个手法别的形态也用吗？**

- 用 → 留在本节的手法库，细则里只留一行引用。
- 不用（该形态独有）→ 才写进细则。

否则六七个条目会各自重复一遍「换支点」，以后改一处要改七处。

### 改完不许自证清白（过度改写的典型形态）

改好一处之后，**不要为了向读者证明「我这里已经干净了」而补一句解释**。

- 例：把「她被吸引但克制住了」改成「她评价了一句腿真长，**除此以外没别的兴趣**」——后半句是作者在替读者下判断，等于承认前半句有问题。**同一段里还留着「这份热闹，她向来提不起兴趣」做收尾，等于同一件事说了两遍**。
- 判据：**把这句解释删掉，读者还能看懂吗？** 能 → 删。能看懂还加，就是自我辩护。
- 更常见的两种同款：
  - 加「（此处已做女性化处理）」式的旁白提示；
  - 心里活动写成评论式总结（「她并不在意这些，她只是……」），而不是具体的判断。
- **为什么危险**：解释句在**网文语感**里最刺眼——原文的旁白是讲故事，解释句是讲道理，一句话就把视角从人物拉回到作者。而且它会随每次返工叠加，改得越多越啰嗦，直接违背「几乎没改」。

### 文风三禁（只约束正文产出）

改出来的正文：**不用破折号、不写自证清白句、不堆 AI 黑话**——批尾通读时逐类过。

- **自证清白句**：判据见上一节（删掉这句，读者还看得懂吗）。
- **AI 黑话**：判据见 4.41 红线（同一 tick 不许每章重复成口头禅）。
- **破折号**：行文纪律，见到即删；**本禁令只针对正文产出，规则文档自身不受限**。

## 4.1 性别确立（最高频的返工点）

- **「提及」＝「出场」**。角色第一次被叫出名字——哪怕只在回忆里——读者就开始按原著脑补性别。**必须在那一句用一个字钉死**。
  - 实测教训：一名同伴在第 3 章只在回忆里被提及、被「他」指代 8 次，却要到很后面才露面。不在这时钉死，中间几十章她都会被读成男的。
- **游戏 / 虚拟世界角色：性别必须在「创建角色」处一次性确立**。这是全书唯一的自然确立点，错过后要花十倍力气补。
- **角色初次出场若不带性别标记，读者会默认按原著理解**——必须在下一次有戏份时用描写确立。
- **性格同样不许预设**：未出场角色不得为了让「类型表」好看而随手分配性格。位置先留空，标注「待原文确认」。
  - 实测教训：同伴团需要差异化，AI 给一个尚未出场（第 32 章才登场）的角色填了「活泼阳光」，用户指出原著里她是「硬核、能打、有胜负欲」的战神。**凭空预设正好违反了项目自己定的「不预设规则」——规则定得好，执行时自己违反。**
  - **性转要动的是「糙」，不是「强」**：功能性的性格内核（硬核 / 能打 / 胜负欲）不含性别，必须保留。

## 4.2 代词

- **代词消歧是硬规则**。性转后女性角色变多，「她」会高频撞车。一段中两个以上女性指代对象，**必须**改用姓名或称谓。

## 4.3 性别张力

- **判断标准只有一句：这一章有没有人看见主角。** 无人互动就没有「被低估 / 被当花瓶」的土壤，硬加只会成为装饰句。
  - 实测：有前台注视的章节加 1 处；只有系统音的章节 0 处。
- **前置判断：原著有没有感情戏——必须问用户，禁止 AI 自行判断。** 它属于改编方向而不是文本属性（原文有单箭头但用户想砍掉、原文很隐晦但用户想放大，都会发生），判错一次，全书 C 类额度都跟着错。
  - 问法：**「这本原著有感情戏吗？有的话保留到什么程度？」** 用户说**有** → 按他给的设计走（保留哪几条线、写到什么程度、结局怎么收），C 类仍按 ≤3 与下文实测节奏，不要自己加码。
  - 用户说**没有** → **C 类直接取 0**，不要在没有注视的章节里「补」暧昧，那是凭空增产。
  - 用户说没有时，女性间情谊走 **B 类**：把原文的兄弟义气、同性之间的调侃改写成女性间真挚感情，**不占 C 类额度**——原文已有这段关系，只是换了性别表达。
  - 踩坑：一本 900+ 章、原著无女主的男频，按默认基线当有感情线的书处理，会把「几乎没改」变成「每章硬凑一处」。
- **每章新增 ≤3 处**，且必须与主线咬合。
- **同一个张力点在不同章节必须换写法**——否则读者会看出套路。实测「被低估」一个点用了 4 种写法：**当场反击 / 不辩解让数字说话 / 不解释因为解释没用 / 手里有底牌根本不必解释**。落点各不相同，但都服务同一个性格内核。

## 4.4 凝视 / 围观类台词——最容易翻车的一条

> **档位：L1 / L2 / L3 都有** —— L1 删词；L2 把笔收回主角的反应；L3 换掉整个围观动机。三档手法差别最大的一条。
>
> **触发词**：`皮肤 / 白嫩 / 身材 / 曲线 / 水蛇腰 / 摸一把 / 盯着看 / 眼馋`

- **禁止照抄**。判断方法：**原句的笑点，建立在「被看的是别人」还是「主角在看」上？** 若属前者、而主角现在成了被看的一方，照抄就会**把喜剧变成性骚扰**。
- **改法**：把围观者动机**泛化**，然后**立刻把笔收回主角的态度上**。
- **边界**：可以有目光、口哨；**不许上手，不许具体描写身体**。
- **关键**：**让张力成立的是她的反应，不是别人的目光。**

### L2 陷阱：反应本身也可能还是凝视（主角与被看者同性时必查）

「把笔收回主角的反应」这个手法有个隐含前提——**反应本身不是凝视**。若主角与被看的人**同为女性**，写成「她也瞄了一眼，但自制力极强，只是扫了一眼便收回视线」，等于把原主的「看」换了个主语，**凝视结构一动没动**；而且更荒谬——女生要看另一个女生的腿，还得靠「极强的自制力」克制。

**判据一句话：这个反应是「欲望」还是「评价」？**

| 反应性质 | 例 | 判断 |
|---|---|---|
| **欲望** | 被吸引 / 忍不住看 / 需要克制 / 想摸 | 凝视结构还在，只是换了主语 → **升 L3** |
| **评价** | 腿真长 / 练体操的底子 / 怎么穿这么少 | 同性视角成立，可留 |

两条配套：

- **同性视角下「所有格化」的身体描写一律删**——「白花花的大长腿」「紧绷青春的象牙感」「白嫩的皮肤」这类，女性不用这种语言描述同性身体，留着就是作者的原视角漏了出来。换成中性事实（「又长又直」）即可。
- **「别人在看」的部分也要查动词**。以为「客观描述旁人的目光」可以照抄，是另一种漏改——「几道视线**黏**在那里」的「黏」本身就是凝视动词，换主语也照样刺眼。改成带社会反应的写法（「偷偷回头瞟，被同桌捅了一下」），既保留旁人目光，又把凝视化掉了。

**反面教训**：一段五句话的描写，第一遍只换了「看的人」，保留了身体形容词和「越是不看越在眼前晃」的诱惑结构，读者第一反应是「女性会这样吗」。**改完必须整段重读，问「这是同性会有的反应吗」**——不要只检查有没有「想摸一把」这种显式词，病灶常常不在词上。

## 4.4b 性暗示场景要换支点，不是换措辞——4.4 的补充（**4.0 的 L3 标准手法**）

> **档位：主 L3** —— 核心动作是换支点。"把词改雅"只是第一步，停在第一步就成了下文的"空壳"。
>
> **触发词**：`黄腔 / 荤段子 / 福利 / 开开眼 / 带你去 / 看姑娘 / 嘿嘿`

> 4.4 管的是「凝视台词照抄会变成性骚扰」；本条管**更隐蔽的另一半**：台词改干净了，场景的动机还挂着。

**特征**：原文的低俗笑点，支点是「男性的性兴趣」——男的想去看女的身体。把具体词换掉（咪咪 / 身材 / 摸一把 → 练得可带劲），字面确实干净了，**但「去看女生」这个动作原封不动**。性转后两个女生手拉手去看女生，读者会问：她为什么去？没有答案。

**为什么 4.4 的「动机泛化」在这里不够**：泛化解决的是「主角变成了被看的一方」，解决不了**「主角也变成了女性」**——原来「男看女」是两个性别，现在成了同一性别，这个动作的驱动力直接消失。**词改了、支点没改，等于留了个空壳。**

**改法：换支点**——把「为什么想去」从**性**换成**另一种低级趣味**（看热闹 / 看出丑 / 蹭便宜 / 八卦）。人物性格（欠揍、手欠、爱撺掇）全部保留，只换驱动力。

| 原文 | 只改措辞（❌ 空壳） | 换支点（✅） |
|---|---|---|
| 配角「你们男生不都是喜欢去社团看咪咪」（男频黄腔，男生之间的玩笑） | 「社团那帮姑娘练得可带劲了，你不去白不去」 | 「她们今天练新动作，说是要在校庆上表演，**我盯了一上午就等着看谁从鞍马上摔下来**——你不去白不去」 |

**判据一句话**：**问「她为什么要去？」——答不出一个与性别无关的理由，就是没改完。** 只能答「因为好看 / 带劲」，说明支点还在性上。

**连带检查**：紧跟的旁白设定必须同步松绑。原「时不时会爆出一些让人难以接受的**黄暴单词**」是给刚才那句黄腔做解释的；台词换了支点，这句也得跟着改（→「嘴上没个遮拦，想到什么说什么」），否则人设与台词对不上，旁白会显得莫名其妙。

**自我校验**：这条最容易在**已改过的句子上复发**——第一遍改动看起来"完成了"（具体词消失了），缺口其实藏在场景的因果里。**所以自检时要重读整段，不是只重读那一句**（通用判据见 4.0）。

**跨章一致性（改完必做）**：**同一个梗 / 同一段黄腔，长篇里往往在后续章节再出现一次**，而且经常是**换了说法**（同一件事第一次写「看咪咪」，第二次写「体操服加白丝美腿」）。只改第一次，两处支点就对不上——一处是「等着看谁摔下来」，另一处又变回「看腿」，读者会觉得人物精神分裂。

- **做法**：改完一处，立刻用**这个梗的场景词**（不是原句的原话）grep 后续章节，命中的登记进待处理表。场景词比原话好使——第二次的说法往往和第一次完全不同，原话搜不到，但「社团」这类**地点 / 事件词**两处都有。
- **改到第二处时**：**照第一次定下的支点写**，不要重新发明。上面那个例子里，第二处应改成「现在连看人从鞍马上摔下来都勾不起你的兴趣了么」，而不是另找一种低俗趣味。
- 同类形态见 4.35c（配角关系设定也会有第二处）。**规律是一样的：一处是症状，两处才是模式。**

## 4.5 描写

- **外貌描写不能沿用男性版**。做法：先拆解原句的**意图**（憔悴 / 底层 / 不修边幅），再用女性视角的等价写法重述——**不是把「普通」改成「漂亮」**。
- **不写与剧情无关的容貌 / 身材描写**。
- **形象落地用具体描写，不贴类型标签**（写「小个子女生、脾气一点就着」，不写「暴躁萝莉」）。
- **现实 / 虚拟两套形象允许有落差，但必须归因于已有设定**（种族体态、虚拟形象优化），**禁止凭空新增世界观**。
- **禁止写胸臀具体大小或「前凸后翘」一类**——与精打细算的人设冲突，且拉低全书调性。要写好看就写**比例、线条、站姿**。
- **曲线靠「走向」写，不靠「部位」写**（上一条的可执行手法）。写**肩线窄、腰身收进去、衣料顺着身体垂下来的轮廓**，读者自然看得出身段；写「胸大 / 臀翘 / 腿白」就是物化。
  - **判据**：删掉这句话，读者还能想象出她的身形吗？能，且**没记住任何具体部位** → 合格。
  - **反面（实测踩过）**：把「不写胸臀」执行成「写得像男生」——「肩背挺得笔直、利落线条」读起来是中性，用户会要求返工。**去特征 ≠ 去物化**，这两件事要同时守住。
  - **成对示例**：✗「胸很大、前凸后翘」 ｜ ✗「身形匀称，肩背挺得笔直」（读不出女性） ｜ ✓「肩线窄而舒展，腰身收得干净，宽大的校服顺着身体垂下来，藏不住那副常年锻炼出来的身段」
- **女性角色独处于男性环境中时，补一笔「为什么不设防 / 为什么有底气」**——不补则显得天真，补了强化人设。

## 4.6 称呼与俗语

- 含性别色彩的俗语**换词不换意**，且**不用另一性别的对应俗语替代**（避免制造新刻板印象）。例：「屌丝」→「穷光蛋」。
- 「兄弟」→ 视语境用「姐妹 / 姐妹几个 / 我们几个」。
- **小名 / 外号先判来源**：由本名演化（取本名的字 / 音 / 义做叠字或变体）→ **随本名一起改**；与本名无关的独立昵称（外号、行当称号）→ 可保留。
  判据：「这个小名是不是只因为有这个本名才存在」。家人按排行起的称呼（老二 / 三儿）单独判，不套用本条。
  - 踩坑：主角本名改了，小名却仍按「独立昵称」保留，导致名字与小名脱节，被用户指出。关键在于**构词逻辑必须跟着换**——原小名是本名的叠字化，新小名也必须是新本名的叠字化（不能随手换个不相干的字），否则家人叫他 / 她时的语感整个断掉。

## 4.7 不动物件

- **背景 / 神话人物不动**（不承担人际关系，改性别零收益，只有破坏世界观的风险）。
- **无性别标记的 NPC（尤其儿童）默认保留**——每多一处改动，就多一处要向读者交代的设定。

## 4.8 一致性

- **改名需全书回溯**，每批校验确认无旧名残留。
- **形象变化（如因生活改善变好看）必须渐进且显式写到**，靠旁人反应或照镜子交代。**不许一夜变美，也不许默认遗忘。**

## 4.9 字面无性别标记的隐性错误（grep 完全失效区）——前三类，第四类见 4.35

**共性**：句子里**没有任何代词、人名、性别标记词**——残留词校验与机械替换一条都报不出来。
**唯一防线是通读时逐句问「这句话 / 这个比喻，放在女性身上成立吗」。**

| 类型 | 例子 | 改法 |
|---|---|---|
| **语义依赖性别的名词**（件数 / 品类 / 部位） | 男主「只剩**一件**内裤」→ 女主「**内衣和内裤**」；护甲穿着部位、更衣 / 洗澡 / 换装、「爆装备后剩几件」的惩罚描写 | 按性别**重算件数与品类**，不是换词 |
| **身体 / 暴力性动词** | 男性配角「**剁了**她」→「**砍回新手村**」；陌生男性「**拉住**她」→「抢到她**面前**」 | **游戏化 / 去接触**——保留意图，去掉肢体暴力与接触动作 |
| **带性暴力意象的比喻** | 「无助地尖叫，**宛如正在被侵犯的小姑娘**」→「像是**被人撬了钱柜的老守财奴**」 | **保意图、换喻体** |

**比喻这一条要单独强调**：前两类管的是「谁对谁动手 / 碰了什么」，这一类管的是**喻体本身带性暴力**——与说话人无关，只要被比喻的是女性角色就直接触碰护栏。
改法一句话：**先确认原句意图（此处＝无助尖叫的喜剧反差），再换成与该角色属性相关的喻体**（该角色是贪婪的地精 → 钱柜被撬）。**喜剧感不减，还顺手强化了人设。**

**顺带一条校验教训**：一旦保留男性配角，「他字零出现」这个指标就失效了——指男性配角的「他」是合法的。指标必须从「零出现」改为「**逐处确认指代对象**」。
**通用教训：指标只在特定前提下成立，前提一变，指标就会骗人。**

> ⚠️ 本表是「三类」，已不完整。后续实测补出**第四类「性别前提句」（见 4.35）**，特征为「字面代词全对、逻辑前提建立在主角是男的之上」。**它才是长篇里最高频的一类。**

## 4.31 「看说话人」——糙话 / 骂阵的唯一判据（长篇最高频）

**一句话**：同一个脏词，出自**主角或已性转角色**之口（**含内心独白**）→ 必改；出自**闺蜜团之外 + 敌对位**之口 → 保留。**功能必须保留**（震撼 / 优越感 / 吐槽不能削）。

**同一个词，两种处置**（这是讲清楚判据唯一有效的方式）：

| 词 | 改（说话人＝主角） | 保留（说话人＝敌对位） |
|---|---|---|
| 装逼 | 主角内心「只有成套了才能**装逼**」→「才够**拉风**」 | 敌方指挥官台词「和我**装逼**」 |
| 牛B | 叙述「再**牛B**的狂战士」→「再**厉害**的」 | 敌对公会台词「牛逼」「尼玛」 |
| 骂阵 | — | 敌方 NPC「该死的」「卑劣的偷袭者」「肮脏的抢劫犯」全留 |

- **判据是「谁在说」，不是「脏不脏」。** 这条同时解释了为什么「他字零出现」这个指标会失效（4.9）。
- **作者可以推翻判据**（实测一例：男学生三句按判据本该保留，被要求去糙）——但**推翻判据时必须连带改叙述**：台词改成「我的天」「氪金狗眼都瞪直了」之后，旁边的叙述「一个个**爆起了粗口**」必须同步改成「**喊了起来**」，否则台词已不糙而叙述仍写爆粗口，前后自相矛盾。**这比判据本身更容易漏。**
- **同批去糙禁用同一个替换词**：一批内多处「牛B」要分别换成「厉害 / 强 / 出彩 / 精良」，全换成「厉害」会让整章听起来像同一个词在复读。
- **换词要保句式**：「有便宜不占**王八蛋**」→「有便宜不占**白不占**」（保住俗语骨架），不要改成书面语。

## 4.32 「看被指的人」——与 4.31 反向，是误伤的另一半

**一句话**：**敌方 NPC 指代女主角时，代词也必须随性转**——判据是「被指的人是谁」，与说话人敌我无关。

- 地精守卫「快和我一起抓住**他**」→ 抓住**她**；卫兵队长「**他**带来了赎罪的金币」→ **她**；NPC 结巴「**他**……**他**……」→「**她**……**她**……」。
- **为什么最容易漏**：改文时会本能地认为「敌人说的话不用动」。但 4.31 管的是**脏词**，**代词不归它管**——**这是两个维度，绝不能合成一条用**。

## 4.33 保留男性的「他」——误伤第一大户

- 保留男性角色（**友善 NPC 也算**：大法师、矮人铁匠）的「他」**全部合法**，不可当残留删。实测一章内可达 **8 处**。
- **泛指不动**：「每个人都有**他**的选择」「由**他**本人承担」「向**他人**低头」「**其他**人」——「其他」读 qí tā，不是残留。
- **防误伤的做法**：把**会反复出现的保留男性 NPC 写进设定表角色处置表并标注「男 · 用他」**。**设定表条目本身就是防误改装置**——写下来就不会靠印象判。
- **判性别不许凭印象**：实测同一章出过正反两例——名字看着像男性、实为**女**（查卡确认）→「他」改「她」；名字看着像男性、实为**男**（敌对位）→ 保留「他」。**两个名字看起来都像男的，查了才知道。**

## 4.34 复数「他们 / 她们」看群体性别**主体**（多数原则：不是「含不含男」）

- **全女队伍 → 必改「她们」**（实测连续 8 章每章都有，漏改第一大户之一）。
- **不要机械按「含不含男」一刀切**——那样会原样继承原著「男主 + 男队友」的男性默认底色，削弱性转后的女性群像感。
- **看群体性别主体**：女性为主体 / 唯一的男是少数或外围队友（如全女闺蜜团 + 1 名男队友）→ 用「她们」；**仅当男性是主体或对半时，才用「他们」**。
- **单指那名男队友本人，仍用「他」**（见 4.33，是另一维度，不冲突）。
- 反例对照：全女小队「**她们**在蛇谷里」改；**5 女 1 男的混合队也应改「她们」**——「**他们**只有六个人」是**原规则会错留的写法**，正是这条要修掉的。

## 4.35 性别前提句——4.9 家族的**第四类**隐性错误（长篇实测最多）

> **档位：主 L1 / L2** —— 换称呼、换动机即可；仅当"动机整个失效"（如房东只要女房客）时才升到 L3 重写场景。

> 4.9 记了三类（件数品类 / 暴力接触动词 / 性暴力比喻）。后续实测发现还有第四类，**且它才是高频。**

**特征**：句子里**代词全对、性别标记全无**，但整句的**逻辑前提**建立在「主角是男的」上。**grep 扫不出，代词校验也扫不出——因为字面毫无问题。**

| 类型 | 例子 | 改法 |
|---|---|---|
| **亲属称谓链** | 「我是她的**哥哥**」/「这做**哥哥**大热天」/「**兄妹**两个」/「房子租给**他们兄妹**」 | 姐姐 / 姐姐 / **姐妹** / **她们姐妹** |
| **长辈的性别化称呼** | 「**小伙子**不要嘲笑」→「**小姑娘**」；「看来这**小子**很有能力」→「这**姑娘**」 | 换称呼 |
| **动机建立在性别上**（最难） | 房东「**只要女房客**」本是把男主挡在门外 → 性转后她本人就符合，动机整个失效 | **换动机，不是换词**：改成「凑不出押三付三」 |
| **调侃句的角度反转** | 「你**一个男人**还觉得吃亏啊」→「你**一个女孩子**还往外赶，也太不把我们当姐妹了吧」 | **改角度保调侃**，不是删；落脚到「姐妹」关系而非「占便宜」，更贴闺蜜打闹语境 |
| **女女之间不成立的说法** | 「**美色**不行，用美食诱惑她」→「**撒娇**不行」（说话人是女的） | 换词，保住「某手段不行→美食」的笑点结构 |
| **同性之间说对方的性别** | 主角（现为女）劝女配：「你**一个女生家**，弄这个也不好」——同性说这话像在撇清自己：「你不行」的潜台词是「我行」 | **改成第一人称复数**：「**咱们俩女生**，弄这个也不好」。把自己一并算进去，劝的分量反而更足，也顺带把「异性说教」变成「同辈相劝」 |

> **判断口诀**：**问「这句话成立，需要主角是男的吗？」** 需要 → 必改；不需要 → 留。
> 这类句子的改法**不是换词而是换动机**。

## 4.35b 性别隔离框架——4.35 家族的**延伸**（跨段落的叙事框架）

> **档位：L3** —— 病灶是跨段落的框架，词级改不动，只能整段拆。局部删几个"女孩子们"不算改完。

> 与 4.35 的区别：4.35 是**单句逻辑前提**建立在「主角是男的」上；本条是**跨段落的叙事框架**——原文靠「其他女性群体（情绪化 / 花瓶 / 美女）」做背景板反衬男主，**性转后主角也是女性，这套性别框架失效且不该留**。

**特征**：用「女孩子们 / 姑娘们 / 女生 / 美女」把一组女性玩家和主角（及同伴）做**性别区隔**，暗示主角「不是普通女孩 / 比她们特殊」，借以衬托。

**判据（grep 辅助）**：在正文 grep `女孩子们|姑娘们|女生|美女|花瓶`；凡命中处把该组女玩家和主角做**性别区隔**的，都属于本条——**不是「有这个词就要改」，是「这个词被用来划性别边界、把她们当衬托背景板」才改**。

**细分：女女互称「美女」**（性转后说话人＋主角多为女性，互称美女 ≠ 必错，要二分）：
- **可保留**：姐妹间自夸俏皮、落脚到关系，而非「美女占便宜」。
- **必改**：把「美貌」当作「对方不该嫌弃自己」的理由（移植自男频「我漂亮你不该嫌弃我」，女性接收端不成立）→ 换成**实际关系**锚点。

**改法（去框架，不删事实）**：
- 去性别标签词：`女孩子们` → `那几个玩家` / `几个人`。
- 去物化 / 花瓶式可信度：`像她这样的美女很少受到质疑` → `身为顶尖公会高手，本就很少被人质疑实力`。
- 去情绪化女性刻板：`受到了伤害，暗自里磨牙` → `被小看了，暗自较劲`（保留「较劲→拼命输出」的喜剧功能）。
- **保留**：合理游戏事实（主角团强、沟通直白、临时玩家较劲）、中性事实描述（如「双胞胎女孩」）、外部粉丝视角（旁人议论她多美，非主角隔离框架）。

**归因型刻板（主角与配角都查，勿漏配角群体）**：把某种**喜好 / 行为 / 性格默认按性别归因**也属同类，且常在配角群体间。grep 抓不到，靠语义体检发现。反例：「被可爱吸引」默认归男、「酸 / 嫉妒 / 议论穿搭」归女 → 去性别归因、中性化或就事论事。

**注意**：判据要**逐处判断**、勿一刀切全改（同一词有该改的、有该留的）。

## 4.35c 关系因果前提——4.35 家族的**第三种形态**（配角的设定反过来打自己）

> **档位：L2 / L3，无 L1** —— 病灶在因果不在词，所以没有"换个词就好"的解法。改法本质是 L2（补一个例外分句）或 L3（整段关系重新交代）。

> 与 4.35 的区别：4.35 讲**主角自己的动机**（房东只要女房客）；本条讲**配角与主角关系成立的理由**。与 4.35b 的区别：4.35b 拿别的女性当背景板衬托，本条根本没提别人。

**特征**：配角出场时被给一段性格设定，字面**既无代词也无性别标记**，看着完全正常——但它的真实功能是回答「**这个人为什么会跟主角做朋友**」，而这个理由建立在「主角是男的」上。主角一变女，这句话**反向否定自己**：一个「和女生玩不在一起」的人，凭什么跟女主是好友？

**判据一句话**：**这段设定，是不是在解释「为什么这两个人来往」？把主角换个性别，理由还成立吗？** 不成立 → 必改。

**改法：保留全部设定，只把「关系成立」从结果改成例外。**
设定一个都不删（性格、爱好、女生缘差、朋友多是男生全留），只在句尾补一个例外落点——主角从「符合条件的结果」变成「破例的那个」。

| 原文 | 性转后的问题 | 改后 |
|---|---|---|
| 「性格有些男孩子气，平日里喜欢动漫什么的，**和女生们玩不在一起，反而好朋友多是男生**。」（原文用以解释她与男主为何是好友） | 她和女生处不来 → 那怎么和女主是好友？读者立刻出戏 | 「跟班上那群女生**玩不到一块去**，好朋友多是男生——**唯独和女主投缘**。」 |

**归类：B 类，不是 C 类。** 补的那句是**修复被破坏的因果连接**，不是为性别转换新增的张力描写，**不占 C 类额度**——算进 C 类会让人误以为「新增描写」是允许的，边界就糊了。

**grep 辅助**：`男孩子气|假小子|女生们|男生们|哥们|像兄弟` —— **仅当紧邻关系陈述**（好友 / 关系好 / 像哥们 / 玩得来）时才算命中。见词就改会大面积误伤（「这哥们」在男性之间、敌对位口中的用法合法）。

**联动检查**：这条一旦出现，几乎必然有第二处——同一段关系往往隔几章又被描述一次（实测第 2 章改完，第 7 章还有一处更直白的「关系就像哥们」）。**改完立刻 grep 该配角名 + 关系词，把后续章节的同类处登记进待处理清单。**

### 变体：分工 / 资格理由（同一病灶，从「关系」挪到「安排」）

4.35c 讲「**为什么这两个人是朋友**」，这个变体讲「**为什么这件事必须由主角来做**」。

**特征**：原文给了一整套协作安排（谁出面、谁经手、谁跑腿），而分工的依据是性别——「她是女生，不好出面办这个，所以要他去做」。

**主角一变女，这套分工立刻失效**，而且失效得很难看：读者会直接反问**「她自己不方便，那另一个女生就方便了？」**

**判据一句话**：这件事的「由谁来做」，是不是按**性别**分的？

**改法：把资格从「性别」换成「她看起来最不像干这个的人」。**
这样两件事都保住了——「为什么非她不可」还在，且完全与性别无关。

| 原文 | 性转后的问题 | 改后 |
|---|---|---|
| 「她之所以拉主角，还有一点：**她是女生，不好出面租给其他人**。所以要主角作为出租人。」 | 两个女生都不方便出面，分工依据消失；同时**「为什么偏偏拉她」这个因果也断了** | 「书买回来总得有人往外租，**她自己脸皮薄，不好去开这个口**。而主角是班里出了名的**正经人**，由她经手这些东西，**谁也想不到是从哪儿来的**。」 |

> **别图省事只改成「两个人都不方便」就收工。** 那等于把原文那个「为什么要拉上她」的因果整段删掉，人物关系也就没了来由。要换的是**理由**，不是**删掉理由**。

## 4.35d 以主角性别为轴的反差句与第三方理由——4.35 家族的**第四种形态**

> **档位：主 L2**（换对照项 / 换理由），极少 L3。病灶不在词，在「跟谁比、因为谁」。

两类同源问题，共同点是**句子的参照物是男性**：

| 类型 | 原文 | 性转后的问题 | 改法 |
|---|---|---|---|
| **反差型俏皮话** | 「哪有**女生**拉着**男生**买小黄书的……」 | 笑点的反差项是「男生」这一侧；主角一变成女生，两个女生一起去买，反差就消失了，句子变成一句普通的陈述 | **把对照项一起换**：「哪有**女生**拉着**女生**去淘这种东西的……」——新反差建立在「两个女生一起去淘这种书」的荒诞上，功能（调侃这件事不像话）保住了 |
| **第三方行为以主角性别为由** | 「她不是脸皮薄，而是知道**有男生一起**，压根就不好意思过来。」 | 第三方不来的理由是「现场有男生」；主角变女后现场没有男生了，**理由整个失效，句子变成没解释** | 换成**不依赖性别的理由**：「知道要买的**是什么东西**，压根不好意思过来。」 |

**判据一句话**：这句的**对照项 / 理由**是「谁」？如果是「男性」→ 换成女性后重问一遍：**这个反差或理由还成立吗？**
- 不成立 → 换对照项或换理由，**不是把句子删掉**（删了会丢原文的调侃功能）。
- 仍然成立 → 不必动。如「她比男生还野」「这丫头片子比男的还敢」，主角变女后照样成立。

**grep 辅助**：`哪有女生|哪有男生|女生还|男生还|一个大男人|女孩子家|有男生|有女生|不像个女的|还算个男人`

**别和 4.4b 混**：4.4b 管的是**场景支点**（她为什么要去 / 这个玩笑的驱动力），这条管的是**旁白或台词的对照项**（跟谁比、因为谁）。同一段里两者可能同时出现，分别处理。

## 4.36 性暗示双关与男性化身体词（性转特有的新增风险）

> **档位：L1** —— 以词汇替换为主（"推倒"→"围殴"、"胸膛"→"胸口"）。判断只在"这个词换不换"，不涉及场景重组。

**女女语境会把原本无害的男频梗变成性暗示**——这是性转项目独有、原作改写不会遇到的。

| 原文 | 改后 | 为什么 |
|---|---|---|
| 「带一群人**推倒**这货」 | 「当 BOSS **围殴一顿**」 | 推倒＝男频性暗示双关 |
| 闺蜜幻想「**扒光他衣服**」 | 「**爆了她一身装备**」 | 女女之间成性暗示；改爆装备**保住原梗** |
| 「大神，**求包养**啊」 | 「**求罩着**啊」 | 包养含性暗示 |
| 「单衣也遮不住的**胸肌**」 | 「遮不住的**身段**」 | 男性身体词 |
| 「她的**胸膛**」 | 「**胸口**」 | 同上 |

- **男性化身体词清单**：胸肌 / 胸膛 / 健壮的身躯 → 身段 / 胸口 / 线条。与 4.5「禁写胸臀」同源。
- **未成年角色去性化**：「二次元来的**小萝莉**」「**萌我一脸血**」→「小姑娘」「太可爱了」；「**控萝莉**的女生」→「**喜欢可爱风**的女生」。
  **但同场景里「酸溜溜女生的穿着 / 山寨货嫉妒」要保留——去性化 ≠ 去冲突。**

## 4.37 保梗原则：只切越界那一半

- **男频脏梗能保就保，只改越界的那一部分**。实例：**带性暗示的玩家 ID**——AI 曾把其中一个谐音梗整个下架；后查证该玩家是女性，**决定保留原名**。
  ⛔ 判据：**带性暗示的 ID，先查角色性别——角色是女性且名字无恶意，可保留原名**；另：该角色若被称「**腐女**」→ 改「**百合女**」（与性转设定对齐）。
  （下架整个梗仍是过度执行。）
- 同类：「瞎了我狗日的**氪金狗眼**」→「**氪金狗眼**都瞪直了」（保住梗本身）。
- **可回退标注**：这类改动**超出性转范围**，属于主动干预，**必须显式标出「可回退」**让用户否决。
- **推论——同一角色名字必须全书一致，这是唯一可以推翻「已完稿不回头」的事项**：改了排行榜里的 ID，就必须回头把前文同一个人的名字也改掉，否则同一角色两章两个名字。

## 4.38 不解释性别——此地无银三百两

- 角色**不需要点破「我们都是姑娘」这类事实**：读者自明，写出来反而像此地无银。
  实测实例：房东「只收女客」场景，原稿让主角点破「我们都是姑娘拦不住」→ 判此地无银，定稿删掉点破，只留「全女屋邻里单纯、带妹妹放心」。
- **判据**：**性别是背景事实，不是需要角色论证的论点。**

## 4.39 去凝视必须保住功能信息

- 4.4 说「去身体评价」，但**删之前先问：这句话在剧情上承担什么功能？**
  实例：「身材超好 / 只穿护住要紧部位的小皮甲 / **有很多色狼慕名而来**」→「慕名而来的玩家不少，一整天围着她什么都不干的也大有人在」。
  **色狼删了，但「围观者多 + 她脾气差会射杀」这个设定必须保住**——否则后文她射人没有铺垫。
- **母题句不删**：「别人以为她只是个哨兵队长，是族里的**美丽花瓶**」——这是 4.3 的「被低估」母题，**主角看穿他人的误判**，删掉就断了母题。**不要见「花瓶」就删。**
- **无性别指向的职业特色与辱骂保留**：「猥琐是盗贼特色」「滚回家吃奶」「装孙子」不动（但若「猥琐」用来形容已性转的闺蜜团成员 → 改「来劲」）。

## 4.40 「下沉」——常驻层超限的唯一处置

> 前期的踩坑几乎都源自这一条没写好：**超限后最常见的错误动作是「逐字挤压措辞」，那是饮鸩止渴。**

- **触发**：常驻文件（规则库 / 设定表角色处置表 / 项目记忆）**超限**。**不是精确命中某个数字**——软目标只是提醒线，**连续两批超**才算真膨胀、才下沉（单次波动不触发）。
- **动作＝整条下沉**：把最情境化的条目**整条移入按需层并留索引**。
  **⛔ 禁止逐字微调措辞来凑字数**——措辞挤压既伤内容又费 token，还制造「文档必须反复维护」的错觉，下次照样超。
- **判层标准**：**改文时随手要用 → 常驻；做法 / 背景 / 论证 → 下沉。** 要问的是「这条是**规范**还是**用法**」，不是「这条长不长」。
- **失控信号**：**压缩类工具调用 ≥3 次即为失控**，无论是否达标。一次写完，复核通过就收工。
- **容器反复超限时，先收紧准入，别先调上限**：实测速查卡上限连调四次仍触顶；收准入（只留「性别＋称呼」）后一次收干。**上调是治标，收准入是治本。**
- **下沉 ≠ 删除**：移走时是**移入**（不是复制）目标层；目标层必须**真的有内容**，否则「论证见 DETAIL」这种**空洞指针比没指针更糟**。
- **对称动作：往常驻层「加」内容前，先做分层自查**——加之前先判一句：这是「改文时随手要用的**判断规则**」，还是「做法 / 清单 / 示例」？前者留核心层（仍要精简）；后者**只放指针**（触发词索引 ＋ 一行指针），细则下沉按需层。
  **判据：核心层「可见」只需「指针 ＋ 关键决策」，不必内联全文——「要可见」≠「要内联」。**
  踩坑：把整份示例清单内联进核心层，等于让每章（含用不到它的章）为清单付上下文钱。

## 4.41 性转角色要补女性化描写（补足性别反差，否则读不出是女性）

> **⚠️ 前置：先问用户「她长什么样」，再动笔补。** 原文第一次出现身材 / 体格 / 相貌描写时，**立刻停下来问**，禁止 AI 自行拍板——这是与「有没有感情戏」同类的**改编方向**问题，不是文本属性。给带默认值的方案逐项确认：**身高**（沿用原著 / 下调 / 更高）、**体型**（匀称结实 / 纤细 / 丰满 / 健气 / 微胖）、**女性化程度**（一眼看得出 / 偏中性常被误认 / 只有细节能看出）、**是否保留原著体格**（力量与耐力，牵动后文体力情节）。问完写进设定表、标注拍板日期，**全书沿用不再重复问**。
>
> **为什么必须问**：一次拍错就是全书级返工——身高胖瘦定下后，每章的体格描写、旁人评价、体型反差都要跟着改。而 AI 的默认倾向是最省事的那个（**照抄原著数字**），那往往不是作者要的。踩坑：原文「身高一米七五、校服下的肌肉健康有力」，只把「肌肉」改成「骨架匀称结实」、身高照留，看着改动最小，实际气质可能整个不对，得用户主动叫停才补问。

> 之前最大的隐性问题：**把「性别转换」做成了「去掉男性编码 → 中性」，却漏了「补上女性编码」。**
> 原作女性角色出场有外貌气质、后续有语气 / 动作 tick，一眼女性；性转角色现在既无男码也无女码，读起来中性、没有女性感——和原作女性角色放一起对比，差距明显。

**原则**：性转角色（由原男 → 女者）在后续改写中**主动补**女性化描写，密度对标原作给其女性角色的写法，让「她是女性」自然成立，而不是靠读者记住「设定上说她是女」。

> **本条是按需层最重的一条（数千字级）**：内部已分层——**① 落笔前必读，②~⑤ 按需查**。监测线（可数）：① 超 1,500 字、或细则行 ÷ 总行数 >1/3、或确认一条判据需 ≥2 次检索 → 触发内部重排（判据 → init.md「判据必须可测」块）。**不拆文件**——拆出去＝多一个「要不要读」的决策点，按需层事实废弃。

### ① 动手前：三道判据（读完就能落笔，②~⑤ 是按需查的）

**闸门 0：这句需不需要让读者感知到她的性别？（最先判，不判会在两个极端之间摆）**

| **需要带**（过下面三关） | **不需要带**（中性就是对的） |
|---|---|
| 首次出场 / 换装照镜 / 独处自省 / 被异性注视或议论 / 身体进入场景（受伤、淋雨、睡觉、湿身）/ 声音第一次出现 | 推进动作 / 战斗 / 解题 / 交易 / 交代信息的对话 |

**只有「需要带」的句子才过三关。「不需要带」的句子中性写就是正确写法，硬加就是往娇气感上推。**

**三闸门：需要带性别信息的句子，缺一不算改完**

| # | 闸门 | 问法 | 不通过 → 怎么办 |
|---|---|---|---|
| 1 | **女性化测试** | 把这句安回原著那个男性主角身上，**完全不违和吗？** | 完全不违和 → 它没承担起「让人看出她是女的」这个任务，换维度或按抓手补 |
| 2 | **场景专属测试** | 把这句换个场景，还成立吗？ | 成立 → 是补丁，删 |
| 3 | **不物化测试** | 有没有性征部位、尺寸、肉感？ | 有 → 按 4.5 改（写走向不写尺寸） |

**闸门 1 只对「需要带」的句子生效。** 它的价值是能当场判真伪（换个人名重读一遍即可，不需要审美）；但**它不意味着「每句都必须违和」——那样等于把「女性」定义成「异常」**。

**闸门 2 的两个例子**（同一个问法，换个场景还成立吗）：
- 成立（「头发贴在颈侧」躺着能写、跑步能写、下雨能写）→ **是补丁，删**
- 只有这个场景能写（「有几缕钻进了嘴里」只有刚睡醒躺着）→ **是描写，留**

### ② 写什么：七个维度与女性化抓手

**维度均衡：别让女码塌缩成头发（实测过的塌缩）**

女码有七个维度，**头发只是其中一项**，却最容易被滥用——因为它**能挂在任何场景上**：站着写垂下来、躺着写铺散、出汗写贴颈、低头写扫到桌子。人物不需要在做任何事，所以它最省力。

- 实测踩坑：前 6 章补了 7 处女码，**7 处全是头发**，且动作高度重复（「贴颈 / 贴脸」3 次、「拨到耳后」2 次、「发绳」2 次）。用户一眼看出「怎么加的都是头发」。
- **头发是「万能补丁」，不是「描写」。**

**换维度只解决「塌缩」，不解决「中性」——每个维度本身也必须女性化。**

实测过的第二次翻车：发现「7 处全是头发」之后，把维度换开了，换成了「抬手按了按发酸的后颈」「后背的衬衫洇着一片深色汗迹」——**维度确实不同了，但这几句安在男主身上一样成立**，读者拿不到「她是女的」任何信息。**换对了维度，仍然是中性描写。**

| 维度 | 写什么 | 中性版 ✗（男女通用） | 女性化版 ✓ |
|---|---|---|---|
| **身体感受** | 力道 / 重心 / 体温 / 酸胀 | 抬手按了按发酸的后颈 | 胳膊上还留着一层被校服捂出来的潮气，抬手按了按发酸的后颈 |
| **动作方式** | 步幅 / 坐姿 / 够高处 / 卷袖口 | 袖子长出一截，把袖口往上卷了两道 | 卷了两道还是盖住半截手背，索性又往上撸了一把，露出细细的手腕 |
| **身体反应** | 惊吓 / 用力之后的失控细节 | 手指还攥着被角，攥得指节发白 | 领口被汗浸得贴在锁骨上，手指还攥着被角，攥得指节发白 |
| **身体形态** | 颈线 / 锁骨 / 肩线 / 腕骨 / 下颌线 / 耳后 / 后颈——**非性化部位**的线条与轮廓 | （已含在形态里） | 颈侧还挂着几滴没干的汗，顺着颈线滑进衣领 |
| **可见痕迹** | 汗 / 泥 / 伤 / 褶皱，落在**皮肤或衣物**上都行（不指性征） | 后背的衬衫洇着一片深色汗迹 | 领口一圈全湿了，贴在脖颈上发凉 |
| **声音** | 气息 / 音量 / 声线 / 开口前的停顿 | 张了张嘴，喉咙里只滚出一声很轻的气音 | 喉咙里只滚出一声很轻的气音——比她自己以为的要细，尾音还抖了一下 |
| **他人反应** | 称呼 / 目光 / 让路 / 递东西 | 同学递了瓶水过来 | 男生递水时手停在半空，改口叫「同学」而不是「哥们」 |

**每个维度的女性化抓手**（不知道该改什么时，从这一列找）：

- **身体感受**：同等的力，她要更用力；同等的距离，她步数更多；冷热、潮气、勒痕这类**贴着皮肤**的感受更明显。
- **动作方式**：穿裙子/校服下摆的顾虑（坐下先压一下、并膝）、够高处要垫脚或搬凳子、袖子裤脚普遍偏长、书包带滑落要扶。
- **身体反应**：出冷汗、手抖、喉咙发紧、耳朵发烫、腿软——**且更容易控制不住声音**。
- **身体形态**：颈线、锁骨、肩线、腕骨、下颌线（见下方白名单）。
- **可见痕迹**：痕迹要落在**能显出身体轮廓**的地方（颈、锁骨、肩胛、手腕），或写清它贴着哪个部位——**同样的汗，写在衬衫后背就只是件湿衣服，写在颈线和锁骨上才有人**。
- **声音**：**声线是性转后唯一改不掉的东西**，最该被用起来——音高、尾音发颤、被吓到时拔高、说话前清一下嗓子。
- **他人反应**：称呼改口、让路让座、递东西时的小心、老师点名时多看一眼。**这是最省力也最真实的一类**（注意 4.4：他人的目光要写成客观描述，但**称呼和行为差异完全可以写**）。

**头发的特殊口径**：**不设全篇上限**，但**第一次要当「设定」写**——明确交代长度样式，读者需要记住她长什么样，不是顺嘴一提。之后每次出现都要有**场景理由**（凑近看书时垂下来挡住视线 → 拨开），不能当装饰；**且不能连续两章用同一个动作**（挡眼 / 拨到耳后 / 贴在脸侧）——跨章换写法不算重复，连续两章同一动作才算。若是中长发，专属细节是**长度带来的麻烦**：钻进嘴里、被压住、卡在衣领、低头时垂到桌面——比「贴在脸侧」具体得多，也不容易重复。

**「不物化」不等于「不写身体」——这是两件事，别混。**

踩坑：第一次写汗，写的是「鬓角汗、碎发贴在脸侧」（塌缩成头发）；换成「后背的衬衫洇着一片深色汗迹」——**表面上是换了维度，实际是把身体藏起来了**：读者只看见一件湿衣服，看不见人。用户指出：「女性脖颈有汗滴这种」。第三次才写成「颈侧挂着几滴没干的汗，顺着颈线滑进衣领」。

- **该避开的是「性征部位 + 男性凝视的写法」，不是身体本身。**
- **可写**：颈、颈线、锁骨、肩线、肩胛、手腕、指节、脚踝、下颌线、耳后、后颈——这些部位**男女身上都存在**，写的是形态和线条。
- **不写**：胸、臀、大腿内侧、腰腹围度等性征部位与尺寸（4.5）。
- **手法同 4.5**：**写走向和轮廓，不写尺寸和肉感。**
- **判据**：删掉这句，**读者能想出她的身形吗？** 只记得一件湿衣服 → 身体被藏起来了；能想出颈线、肩线，但没记住任何性征部位 → 合格。

> 这条和 4.5 是同一件事的两端：**4.5 防的是「写性征」，这条防的是「为了不写性征而把身体整个拿掉」。** 两边都要守，中间那条路是「非性化部位的线条」。

### ③ 写多少：触发范围、密度与频率

**触发范围（不看互动对象，看有无气质流露空间）**：
- 独处 / 自照 / 整理装备 / 换装时流露的气质（"她做事的样子"）；
- 与**任意**角色互动的神态反应——队友拌嘴、敌人轻蔑、NPC 搭话、路人注目都算，**不限于闺蜜同框**；
- 被凝视 / 被评价时的反应；
- 做事的节奏与姿态（战斗的优雅、算账的专注侧脸、收尾的利落）；
- 化形 / 外貌相关时刻。
- 仍**不触发**：纯数值装备流水、无神态空间的大段系统说明。

**密度 / 频率口径**：**场景触发式，不设「每章保底 N 处」配额**。有气质流露空间的章，通常 **1–3 处**；纯数值 / 装备流水、无神态空间的系统说明章**为 0**（不加）。总锚是「**密度对标原作给其女性角色的写法**」——拿原著同类场景做标尺，而非凑数字。

**场景类型也要判（恐怖 / 紧张场景是例外）**：惊悚、生死关头、追逐、搏斗这类场景，**补女码要极轻，甚至可以整段不补**。它们的节奏建立在「来不及想」上，插进发丝、气味、姿态会让紧张泄气——**这时女性化让位给节奏，留给后面平静的段落补回来**。
- 实测：一整章噩梦（僵卧不能动 → 脚步骤近 → 掀被子抓人 → 梦里穿行暗红走廊），**只在开头补一句**，全章不再补。
- 那处最初写的是「头发铺散在枕面上」，后来被换掉。它同时说明两件事：**恐怖场景确实只需要一句；但这一句本身必须是场景专属的**。定稿改成「张了张嘴，喉咙里只滚出一声很轻的气音」——交代她醒着、强化「动不了也喊不出」，而且只有鬼压床这个场景能写。
- 判据：**这句加进去，紧张感变强了还是变弱了？** 变弱 → 撤掉。

**⚠️ 频率口径：不设全篇次数上限，只防「同一处的重复」**

较早的写法是「同一维度全篇 ≤2 次」——**这条已废弃**：900+ 章的长篇按它执行，后半程会没有维度可用，反而逼人反复使用「他人反应」这类最泛的维度。实测反馈（2026-10-19）：**「全篇 ≤2 次……后面都不知道加什么了」。**

改成三条：

1. **一个场景内，同一个动作只写一次。** 拨头发、擦汗、攥手、按后颈——同一段里出现第二次就换。**重复才是问题，次数不是。**
2. **一批（10 章）复盘时看比例：单一维度不超过该批女码总数的 1/3。** 是比例不是绝对数——这批写了 12 处、头发 4 处没问题；写了 3 处全是头发，才叫塌缩。
3. **根本判据仍是「换个场景还成立吗」。** 每处都是场景专属的描写，重复天然不会发生；**次数只是复查兜底，不是写作配额。**

**应用范围**：默认**仅后续新章**生效（符合「已完稿不回头」）；已写章节由作者指定若干做**回填**，届时按本条对指定章节的关键场景补女性化描写。

### ④ 红线

**红线：女性化 ≠ 柔弱化**

> 读者要看出「她是女的」，靠的是**形态、声线、穿着、他人的反馈**；不是靠**力气变小、胆子变小、更常被保护、更在意形象**。
>
> - 可以写：手腕白皙（形态）／开口的声音比自己以为的细（声线）／别人改口叫「同学」而不叫「哥们」（他人反馈）
> - 不能写：拧不开瓶盖、被吓得尖叫、需要人拉一把、原来打得过的人现在打不过（**能力与性格降级**）
> - **判据：改完之后，她做同一件事的难度变了吗？变难了 → 越界，撤。**
>
> 性转改的是**身体与观察视角**，不改**能力、性格、判断力**。踩坑：「不违和就要重写」这句话按字面执行，会把所有中性动作都往「娇气」方向改——**这是另一种刻板印象（4.35b 归因型刻板的镜像）**。

**红线（不可越）**：
- 不写胸臀具体（4.5）；不露骨（4.10-2）；未成年 / 幼态角色不性化（4.10-1/4）。
- 不凝视物化（4.4）：描写是她「作为女性存在」的自然痕迹，不是「被看的身体」。
- 活人感：自然嵌入、避免清单式堆砌、避免每章重复同一 tick 成 AI 黑话；用「少量、分散、因景制宜」取代「逢女必写」。
- **轮换防重复**：同一 tick 不在相邻 / 近距章重复；同一角色相邻出场不重复同一动作——防「翻来覆去就那几个词」。
- 比例克制：补的是「读得出是女性」，不是把每个性转角色写成花瓶 / 媚态；**按各自人设取女性化面向，不统一媚化**（面向因书因人而异）。
- **措辞红线**：补女性化描写时**禁用偏男性的形容词**——「俊美 / 英俊 / 俊朗 / 棱角分明 / 硬朗 / 五官深刻」等多用于男性，落在女角色上会错位、读不出女性感。改用女性化但非柔媚的词：清秀 / 清丽 / 秀丽 / 利落 / 挺拔 / 飒爽 / 明丽 / 眉眼疏朗 / 线条干净等。
- **还原男频中性词男性化**：原文为男频，大量**本应中性的词**被写成男性化说法，性转时应还原回中性表达，**不是机械去「爷」字**。常见映射：有钱人称谓「款爷 / 大爷（仅指金主义）」→「大款 / 有钱人 / 金主」；群体硬汉称呼「纯爷们 / 铁血汉子」→视语境中性化（如「铁血好手」）。**区分**：① 中性通用词（土豪 / 大款 / 朋友 / 同辈哥们）保留；② 玩家 ID 含「爷」不改；③ 职业戏称「法爷」等中性调侃不改。

**主角颜值口径（各书自定，通用原则）**：现实 / 游戏**分层**、**肯定底子**、**不沿用原文对原男主的否定式外貌表述**（把「不如想象」归因于「非绝世美人」而非「丑 / 没潜质」）。游戏内场景不得写「营养不良 / 气色差」这类只属于现实早期状态的描写。

### ⑤ 落地：登记与联动校验

**设定必须登记**：外形一旦写定，进设定表并注明**首次交代位置**。踩坑：主角发型只在正文写过一次「齐肩」，没进设定表，**连用户都记成了「齐耳短发」**（把另一章的配角发型、开篇那名白衣女子的发型记混了）。**设定不登记，读的人——包括作者本人——就会记错。**

**三类落点**：
1. **首次 / 重要出场补外貌气质**：用具体描写落地（不贴标签，见 4.5），且**与各书已确立的人设形象一致**。写**比例 / 线条 / 站姿 / 声线 / 眉眼气质**，**不写胸臀具体部位**（4.5）。注意**「不写胸臀」不等于写成中性**——曲线要用「走向」写出来，否则读不出女性，反而返工（见 4.5 的成对示例）。
2. **后续按人设分化的 tick 库**（**禁套通用女性词**；从角色自身 / 中性视角落笔，不写成被围观的物件，见 4.4）：每个角色有自己的气质面向与 tick 池（清冷型 / 阳光型 / 利落型 / 火爆型…），照该人设**现造**贴合的词。**具体名单因书而异**，建在该书自己的设定层里，不进通用 skill。
3. **状态 / 姿态气质层**（最耐读、最不像清单）：不靠固定动作词，靠「她做事的样子」流露——如算账时「笔尖顿了顿、侧脸很静」、收装备「动作利落得像在跳舞」、临敌「眼微微眯起、像在丈量距离」。

**库内词是「调子锚」，不是「白名单」**：各角色的 tick 列表**只是示例**，用来标定其气质方向，**不是只许循环这几个词**。
- **正解**：按该角色**当前场景**的气质面向，**现造**贴合的词 / 动作 / 状态；库内词只用于**校准方向**与自查（新造词不能越出该角色气质——清冷型别出现娇嗔、阳光型别出现妩媚）。
- 库内词可以用，但**同词不近距重复**；多数时候应换成**气质相同、字面不同**的新表达。
- **轮换规则防的是「重复」，不是「必须从库里挑」**——把库当封闭白名单循环，等于把「词穷」原样再犯一遍。
- 一句话判据：**库里的是「像这样」，不是「就用这个」。**

**改性别词不能只换形容词（联动校验——易漏的通用坑）**：
- 性转改写里「他→她 / 帅→美 / 俊→美」这类替换，**必须连带检查主谓、指代、主语逻辑是否成立**，光替换形容词会留下逻辑悬空。
- 反例：原文「小女生们憧憬着主角有多**帅**」顺（女粉磕帅哥）；只改成「有多**美**」后，主角变女性，「女粉磕美女」的主语逻辑就错位了。正确做法是把主语也改中性：「游戏里那些憧憬着主角有多美的**颜狗**」——既保住「冲颜值来、注定失望」的梗，又去掉性别错位主语。
- **凡做性别替换，顺手核验三件事**：① 被替换词的修饰对象现在性别是否自洽；② 该句的主语 / 谓语 / 指代在性转后是否仍成立；③ 周围视角（如邻句「这姑娘」「那小子」）是否一致。任一不成立就要改的不是形容词本身，而是那一层逻辑。

### ⑥ 维护须知（改文时可跳过）

**元规则：写规则时，示例必须覆盖 ≥3 个不同维度，禁止同一维度的例子在文件里重复出现。**
原因：曾把「后背的衬衫洇着一片深色汗迹」当成"可见痕迹"的正面范例写进本表——**它既是错的写法，又让这个维度在示例里占了不该占的份量**，等于规则自己在教错误。示例一维独占，规则就退化成一维。

**与 4.35b 的关系**：不冲突。4.35b 去掉「拿其他女性做背景板衬托主角」的框架；本条是给性转主角 / 同伴自己补女性化描写，让她也「读得出是女性」。

**与「逐段精修每章 ≤3 处」的关系**：那条是针对「删 / 改男性编码」幅度的旧口径，本条是**加**女性编码，属另一维度，不计入那 3 处的削减额度，但同样遵循「少量、自然、不抢戏」。

## 4.10 硬护栏（不可协商）

1. **未成年角色严格排除在感情线外**，全部亲情向，不做任何性化处理。
2. **不产出露骨性描写**。
3. **改写他人作品公开发布可能侵权**（需主动提示用户；自用练笔无碍）。
4. **形象幼态的成年角色必须在设定表显式标注「成年」**，防止被误读为未成年。

> 这四条在一个项目里应有**唯一权威处**；别处只留一行指针。**唯一例外**：若某处是「只读它、不读权威文件」的，那里必须留一行指针（否则会用错口径）。修改条款时，指针指向的权威处先改。
