## 4.0 总纲：语境前提失效——4.x 全家的母问题（**先读这一节**）

**一句话**：性转不能只替换代词，还要复核受影响的叙事视角与因果。原文有些场景、笑点、描写或动机依赖主角或叙述者为男性；前提变化时可能要处理整段。**不预设原文所有欣赏、关系或中性动作都因此失效。**

**七种形态**（细则各自独立，此处只做索引——**它们经常同时出现在一段里**）：

| 形态 | 表现 | 细则 | 档位 |
|---|---|---|---|
| **物化视角** | 把人物简化为供观看或占有的身体；不等于一切欣赏 | 4.4 / 4.5 | L1 / L2 / L3 |
| **性暗示场景** | 低俗笑点的支点是男性的性兴趣 | 4.4b | 主 L3 |
| **刻板印象** | 机械继承偏见或因性转新增女性群体归因 | 4.35b / 4.35e | L2 / L3 |
| **性别前提句** | 字面代词全对，逻辑前提是"主角是男的"；**含以主角性别为轴的对照项与第三方理由**（「哪有女生拉着男生…」「因为有男生在场」） | 4.35 / 4.35d | 主 L1 / L2 |
| **性别隔离框架** | 群体指称沿旧名单，或原女性退缩、性转角色包办判断与保护 | 4.35b | L3 |
| **关系因果** | 配角设定在解释"为何和男主是朋友" | 4.35c | L2 / L3（无 L1） |
| **身体词 / 双关** | 男频梗在女女语境下变成性暗示 | 4.36 | L1 |

**「档位」＝这条通常要动到哪一层。** 标「主 L3」不是"只能 L3"，而是"词级改不动、必须重写场景"。**档位标记的用处**：某条只有单一档位，说明它不用再拆；三档都有的（如男性凝视），才值得在正文里分三小段写。

**这份清单是开放的，不是穷举。** 4.x 每新增一条，先判它属于哪一种形态、挂到本表；**挂不上去说明是新形态，就在表里加一行**——表本身要随实测长。

### 粒度：先判病灶在哪一层，再决定改多少

**两个维度不能互相替代**：**形态**决定「往哪个方向改」，**粒度**决定「改多深」。同样是 L3（整段重组），凝视是「把笔收回主角的反应」、性暗示是「换支点」、关系因果是「补例外」——**方向完全不同**；反过来，同为凝视，L1 删一个词、L3 重写一段，剂量差十倍。

**判错层，改多少都没用。**

| 档 | 病灶位置 | 通用手法 |
|---|---|---|
| **L1 词级** | 只在称呼 / 身份 / 身体词上 | **换词** |
| **L2 句级** | **句子的动机**建立在性别上 | **换动机**、保句式、改角度 |
| **L3 语境级** | **整段场景的驱动力**建立在性别上 | **换支点**、重组语言、转移焦点 |

**手法是跨形态共享的。**「换支点」不专属性暗示——凝视、关系因果、刻板印象在做 L3 时都会用它。所以**细则条目只写该形态独有的陷阱与判定，通用手法不重复写**。

### 判据（改完必做）

**把这一段当成一个全新的场景重读**，问「读者会不会停下来问『为什么』？」

- 不会 → 改对了，进下一句。
- 会（「她为什么要去？」「她为什么在意这个？」「她俩怎么会是朋友？」）→ **病灶在更上面一层，升一档重做**。

**一段里多种形态并存时**（既有男凝又有低俗笑点），按**最上面那一层的粒度**处理，不逐句打补丁。

> **不是「改得少」有问题，是「改成哪一层」有问题。** skill 要的是「改动最小」，不是「粒度最浅」——**最小＝恰好够的那一层**。别因为怕改多就不敢升档；反过来，病灶确实在词上就别硬升档，那是过度改写。两个方向各一个实测：3 字到位的见 4.35，改 40 字仍不够的见 4.4b。

### 防膨胀：细则该写什么

写细则时一旦开始写「怎么改」，先问一句：**这个手法别的形态也用吗？**

- 用 → 留在本节的手法库，细则里只留一行引用。
- 不用（该形态独有）→ 才写进细则。

否则六七个条目会各自重复一遍「换支点」，以后改一处要改七处。

### 改完不许自证清白（过度改写的典型形态）

改好一处之后，**不要为了向读者证明「我这里已经干净了」而补一句解释**。

- 例：把「她被吸引但克制住了」改成「她评价了一句腿真长，**除此以外没别的兴趣**」——后半句是作者在替读者下判断，等于承认前半句有问题。**同一段里还留着「这份热闹，她向来提不起兴趣」做收尾，等于同一件事说了两遍**。
- 判据：**把这句解释删掉，读者还能看懂吗？** 能 → 删。能看懂还加，就是自我辩护。
- 更常见的两种同款：
  - 加「（此处已做女性化处理）」式的旁白提示；
  - 心里活动写成评论式总结（「她并不在意这些，她只是……」），而不是具体的判断。
- **为什么危险**：解释句在**网文语感**里最刺眼——原文的旁白是讲故事，解释句是讲道理，一句话就把视角从人物拉回到作者。而且它会随每次返工叠加，改得越多越啰嗦，直接违背「几乎没改」。

### 文风三禁（只约束正文产出）

改出来的正文：**不用破折号、不写自证清白句、不堆 AI 黑话**——批尾通读时逐类过。

- **自证清白句**：判据见上一节（删掉这句，读者还看得懂吗）。
- **AI 黑话**：留意 4.41 的模板复查；重复只是候选，结合功能和语境判断，不自动换词。
- **破折号**：行文纪律，见到即删；**本禁令只针对正文产出，规则文档自身不受限**。

## 4.1 性别确立（最高频的返工点）

- **首次提及也须清楚确立性别，但不等于真正登场**。角色第一次被叫出名字——哪怕只在回忆里——可用正确代词或称呼交代已定性别；外貌建立另按 4.42。
  - **「一个字」只管「她是女的」这个事实**（代词 / 称呼层）；「她是什么样的女性」属于 4.41 / 4.42，按真正登场、重要程度与文风建立，不在回忆提名处硬塞外貌。
  - 实测教训：一名同伴在第 3 章只在回忆里被提及、被「他」指代 8 次，却要到很后面才露面。不在这时钉死，中间几十章她都会被读成男的。
- **游戏 / 虚拟世界角色：性别必须在「创建角色」处一次性确立**。这是全书唯一的自然确立点，错过后要花十倍力气补。
- **角色初次出场若不带性别标记，读者会默认按原著理解**——必须在下一次有戏份时用描写确立。
- **性格同样不许预设**：未出场角色不得为了让「类型表」好看而随手分配性格。位置先留空，标注「待原文确认」。
  - 实测教训：同伴团需要差异化，AI 给一个尚未出场（第 32 章才登场）的角色填了「活泼阳光」，用户指出原著里她是「硬核、能打、有胜负欲」的战神。**凭空预设正好违反了项目自己定的「不预设规则」——规则定得好，执行时自己违反。**
  - **性转要动的是「糙」，不是「强」**：功能性的性格内核（硬核 / 能打 / 胜负欲）不含性别，必须保留。

## 4.2 代词

- **代词消歧是硬规则**。性转后女性角色变多，「她」会高频撞车。一段中两个以上女性指代对象，**必须**改用姓名或称谓。

## 4.3 性别张力

- **外部反应型张力先查：谁观察或评价了主角？** 新增「被低估 / 被当花瓶」等外部反应须有相应观察者及事实依据，不能在纯系统说明中凭空添加。这只是外部反应的条件，**不是所有 C 类新增的准入标准**。
  - 私下的感情认知、回忆或对关系的预期可以没有当场旁观者，按已定方向、视角、前文信息、当前场景和必要性判断（4.45）。
- **前置判断：感情戏份准备怎么处理——必须问用户，禁止 AI 自行判断。** 问的是改编意图，不是原著有没有：原著有没有是文本属性，读得出来；用户想怎么改是改编方向，只能问（原文有单箭头但用户想砍掉、原文很隐晦但用户想放大、原文没有但用户想新增，都会发生），判错一次，全书 C 类额度都跟着错。
  - 问法：**「感情戏份准备怎么处理？」** 给档位不给开放式问题，常见档位：**全部去除** / **保留原文** / **放大原文** / **新增一条** / 用户自定义；档位只是起点，用户可给任意方案。
  - 用户选**保留 / 放大 / 新增** → 按他给的设计走（保留哪几条线、是否新增、写到什么程度、结局怎么收），C 类仍按每章 ≤3 处上限，不是保底；进展按 4.44 / 4.45，不照搬单书节奏。
  - 用户选**全部去除** → 原文感情线删掉或背景化，**恋爱向的新增张力一律不写**，不能以补描写为由另加暧昧；此时女性间情谊走 **B 类**：把原文的兄弟义气、同性之间的调侃改写成女性间真挚感情，**不占 C 类额度**——原文已有这段关系，只是换了性别表达。
  - **C 类总量与感情戏处理解耦**：即使全文无恋爱，有依据的非恋爱向性别张力仍可写。被低估 / 被当花瓶等外部反应须满足上面的观察条件，其他新增按各自语境判断，不强求旁观者。
  - 踩坑：一本 900+ 章的男频，因没问用户意图、按默认基线当有感情线的书处理，把「几乎没改」变成「每章硬凑一处」。
- **C 类新增关系 / 性别张力每章 ≤3 处**，且须与主线咬合；必要修复归 B、首次设定确立归 E，不能把所有新增句都算 C。上限不是配额。
- **同一个张力点反复出现时检查是否机械复读**，无需为了换词而换词；可按人物反应、场景与功能选择写法。实测「被低估」一个点用了 4 种写法：**当场反击 / 不辩解让数字说话 / 不解释因为解释没用 / 手里有底牌根本不必解释**。落点各不相同，但都服务同一个性格内核。

## 4.4 凝视 / 围观类台词：先判视角与人物功能

> **档位：L1 / L2 / L3** —— 只坏一个词就换词；动机或整段视角失效时，按 4.0 升档。
>
> **触发词**：`皮肤 / 白嫩 / 身材 / 曲线 / 水蛇腰 / 摸一把 / 盯着看 / 眼馋 / 被吸引 / 克制`

**不因观看者性别或产生吸引就判物化。** 女性可以欣赏女性，也可以产生符合既定感情方向的吸引；「忍不住看」「需要克制」须读完整语境，不能自动删除。身体描写的完整边界只按 **4.5**。

先判断原段承担什么：审美欣赏、恋爱吸引、围观喜剧、敌意冒犯，还是把人物当供观看或占有的身体。再核对人物关系、视角和当前进度。不能把原男主的性兴趣当成女主的默认动机，也不能反过来断言同性之间不会有这种兴趣。

- **成立则保留**：如两名成年女性在已定关系下互相吸引，或女粉丝欣赏女角色的外貌；不为证明「已去凝视」补「除此以外没有兴趣」。
- **原机制失效则修复**：围观笑点若因主角成为被看者而变成冒犯，要保住剧情和人物功能，必要时泛化围观动机、写出她的应对，或重组场景。她的态度不必总是羞怯或回避。
- **动词也结合叙述立场判断**：「黏着看」可能在渲染身体供人消费，也可能在表现她不悦的骚扰经历。不能仅换主语就算修好，也不凭一个动词定案。无必要的骚扰与接触不新增；原有冲突按功能处理，不把女性角色自动写成不能反抗。

**成对反例**：
- ✗「她也是女生，不可能被另一个女生吸引」→ 用观看者性别代替人物判断。
- ✓ 已定直球感情线：「她笑起来很好看。她多看了一眼，仍把话题接回了正事。」→ 欣赏与行动均有语境，按 4.5 复核即可。
- ✓ 若原段扫描部位并把对方当战利品，删改物化的表达，保留必要的相识、冲突或信息；不额外安排自我辩护。

## 4.4b 性暗示场景：机制失效时换支点，不只换措辞

> **档位：主 L3**；**触发词**：`黄腔 / 荤段子 / 福利 / 开开眼 / 带你去 / 看姑娘 / 嘿嘿`

本条查的是「词改了，场景的动机是否还成立」。性转后不预设性兴趣消失，也不照搬原男主的兴趣。自然欣赏、合理吸引按 4.4 / 4.5 / 4.45 判断；低俗笑点不能仅靠换雅词冒充完成。

**问「她为什么要去？」** 答案须符合她的人设、已定感情方向与当前情境。「因为表演好看」「因为喜欢那个人」可以成立；不能强迫所有理由与性别或吸引无关。若原黄腔的驱动力确已失效，换成适合该人物的支点，如看热闹、看新节目、蹭便宜或探消息，不强制改成另一种低级趣味。

| 原桥段 | 未改完 | 可选处理 |
|---|---|---|
| 朋友用露骨身体笑话撺掇主角去看社团训练 | 只把身体词换成「练得可带劲」，人物仍无缘由去 | 按剧情改为看校庆新动作；若人设本来热衷看出丑，可留其恶趣味；若本来欣赏某位成年表演者，也可保留自然欣赏 |

**连带检查**：台词改成普通调侃后，旁白「常爆黄暴单词」等解释也须同步修复，保住爱撺掇、嘴快等人物功能。

**跨章一致性**：同一梗可能换说法复现。改完用地点、事件、关系等场景词检索后文，把候选登记待处理；后续沿用已定支点，除非剧情明确改变了动机。只搜原话可能漏查，仍需通读相关场景。

## 4.5 身体、外貌与欣赏（不物化的唯一权威定义）

允许根据**已定形象、叙述视角与当前情境**描写外貌、气质、整体身形和身体细节；不以身体部位名称直接判定违规。功能性身体描写、自然审美欣赏与符合既定关系进度的吸引均可保留。**不物化、不露骨，不用性征尺寸或扫描式部位堆砌制造看点，不把人物简化为供观看或占有的身体。** 判定须读完整语境，不根据观看者性别或是否有欲望下结论。硬护栏见 4.10。

- 外貌不能机械沿用男性版：先保留原句的意图（憔悴、底层、不修边幅等），再按已定女性形象重述；**不把「普通」自动改成「漂亮」**。偏男性外貌措辞按 4.41④ 的个人偏好修改。
- 身体感受、胸前护甲受力、伤口处理等功能性细节可以写。胸、臀、大腿等词不是禁词；服装尺寸、装备适配等事实也不因含数字自动成为物化，须判断其功能与叙述方式。
- 外貌、声线、神态、语气、动作方式、内心和关系互动都能塑造人物。允许「清冷」「漂亮」等直接形容和中性动作；具体描写是优先手法，不是唯一合法手法。
- 不堆与当前叙述无关的容貌身材描写。描写可以服务于场景、动作、视角、回忆、反差或气氛，不限定只有几种理由，也不要求换个场景就不能成立。
- 现实 / 虚拟形象允许有落差，但归因于已有设定，禁止凭空新增世界观；不把现实早期的营养不良等状态随意移到不同设定的虚拟形象。
- 类型标签不能替代人物塑造（如只写「暴躁萝莉」）；幼态成年角色须按 4.10 登记。女性独处于男性环境中也不默认天真或必须补胆量说明，按实际风险、人物能力和已有因果判断。

**复核方式**：检索身体词、尺寸词只定位候选；阅读前后文，说明该句在写什么、是否把人缩成身体、是否堆砌或重复。再看整段能否形成符合设定的具体人物，不用「删一句后还记不记得性征」作为测试。

**成对示例**：
- ✗ 叙述停下来逐项报胸腰臀尺寸，只为供读者品评 → 去掉物化清单，保留当前场景需要的信息。
- ✓「护甲在胸前绷紧，她换了只手，催同伴快走。」→ 动作与装备受力，有功能，不据「胸」字删句或削弱力量。
- ✓「她眉眼清丽，开口却很干脆。」→ 允许直接外貌形容与声音反差，不强塞微动作。
- ✓「衣料顺着腰线垂下，她站得很直。」或「她的衬衫后背湿了一片。」→ 是否保留看状态、节奏与重复，不因男女通用判不合格。

## 4.6 称呼与俗语

- 含性别色彩的俗语**换词不换意**，且**不用另一性别的对应俗语替代**（避免制造新刻板印象）。例：「屌丝」→「穷光蛋」。
- 「兄弟」→ 视语境用「姐妹 / 姐妹几个 / 我们几个」。
- **男性尊称看所指，不看字形**：如「老大」可称女性，已有职务可用职务，但不统一换「大佬」；「大哥」等若确指男性身份才随角色处理。排除「老大劲」等非称呼用法，保留亲疏、等级和口吻。
- **小名 / 外号先判来源**：由本名演化（取本名的字 / 音 / 义做叠字或变体）→ **随本名一起改**；与本名无关的独立昵称（外号、行当称号）→ 可保留。
  判据：「这个小名是不是只因为有这个本名才存在」。家人按排行起的称呼（老二 / 三儿）单独判，不套用本条。
  - 踩坑：主角本名改了，小名却仍按「独立昵称」保留，导致名字与小名脱节，被用户指出。关键在于**构词逻辑必须跟着换**——原小名是本名的叠字化，新小名也必须是新本名的叠字化（不能随手换个不相干的字），否则家人叫他 / 她时的语感整个断掉。

## 4.7 不动物件

- **背景 / 神话人物不动**（不承担人际关系，改性别零收益，只有破坏世界观的风险）。
- **无性别标记的 NPC（尤其儿童）默认保留**——每多一处改动，就多一处要向读者交代的设定。

## 4.8 一致性

- **改名需全书回溯**，每批校验确认无旧名残留。
- **形象变化（如因生活改善变好看）必须渐进且显式写到**，靠旁人反应或照镜子交代。**不许一夜变美，也不许默认遗忘。**

## 4.9 字面无性别标记的隐性错误（grep 完全失效区）——前三类，第四类见 4.35

**共性**：句子里**没有任何代词、人名、性别标记词**——残留词校验与机械替换一条都报不出来。
**唯一防线是通读时逐句问「这句话 / 这个比喻，放在女性身上成立吗」。**

| 类型 | 例子 | 改法 |
|---|---|---|
| **语义依赖性别的名词**（件数 / 品类 / 部位） | 男主「只剩**一件**内裤」→ 女主「**内衣和内裤**」；护甲穿着部位、更衣 / 洗澡 / 换装、「爆装备后剩几件」的惩罚描写 | 按性别**重算件数与品类**，不是换词 |
| **身体 / 暴力性动词** | 威胁、拉住、受击等在新语境下是否改变危险程度、视角或动作因果 | 保留战斗、冲突与行动能力；不因被指者为女性一律去暴力或去接触。只有新增无必要骚扰、功能失效或触及 4.10 时修复 |
| **带性暴力意象的比喻** | 「无助地尖叫，**宛如正在被侵犯的小姑娘**」→「像是**被人撬了钱柜的老守财奴**」 | **保意图、换喻体** |

**比喻这一条要单独强调**：前两类管的是「谁对谁动手 / 碰了什么」，这一类管的是**喻体本身带性暴力**——与说话人性别无关；把性暴力当喜剧喻体应改为符合人物的非性暴力比喻，具体硬护栏见 4.10。
改法一句话：**先确认原句意图（此处＝无助尖叫的喜剧反差），再换成与该角色属性相关的喻体**（该角色是贪婪的地精 → 钱柜被撬）。**喜剧感不减，还顺手强化了人设。**

**顺带一条校验教训**：一旦保留男性配角，「他字零出现」这个指标就失效了——指男性配角的「他」是合法的。指标必须从「零出现」改为「**逐处确认指代对象**」。
**通用教训：指标只在特定前提下成立，前提一变，指标就会骗人。**

> ⚠️ 三类之外还有**第四类「性别前提句」（见 4.35）**——字面代词全对、逻辑前提建立在主角是男的之上。**它才是长篇里最高频的一类。**

## 4.31 「看说话人」——个人去糙要求（长篇最高频）

**一句话**：同一个脏词，出自**主角或已性转角色**之口（**含内心独白**）→ 必改；出自**闺蜜团之外 + 敌对位**之口 → 保留。**功能必须保留**（震撼 / 优越感 / 吐槽不能削）。

**同一个词，两种处置**（这是讲清楚判据唯一有效的方式）：

| 词 | 改（说话人＝主角） | 保留（说话人＝敌对位） |
|---|---|---|
| 装逼 | 主角内心「只有成套了才能**装逼**」→「才够**拉风**」 | 敌方指挥官台词「和我**装逼**」 |
| 牛B | 叙述「再**牛B**的狂战士」→「再**厉害**的」 | 敌对公会台词「牛逼」「尼玛」 |
| 骂阵 | — | 敌方 NPC「该死的」「卑劣的偷袭者」「肮脏的抢劫犯」全留 |

- **判据是「谁在说」，不是「脏不脏」。** 这条同时解释了为什么「他字零出现」这个指标会失效（4.9）。
- **作者可以推翻判据**（实测一例：男学生三句按判据本该保留，被要求去糙）——但**推翻判据时必须连带改叙述**：台词改成「我的天」「氪金狗眼都瞪直了」之后，旁边的叙述「一个个**爆起了粗口**」必须同步改成「**喊了起来**」，否则台词已不糙而叙述仍写爆粗口，前后自相矛盾。**这比判据本身更容易漏。**
- **去糙后复查口吻与重复**：如「牛B」可按功能换「厉害 / 强 / 出彩 / 精良」，不是机械同义词轮换；合理重复可留，避免整章失去人物声音。
- **换词要保句式**：「有便宜不占**王八蛋**」→「有便宜不占**白不占**」（保住俗语骨架），不要改成书面语。

## 4.32 「看被指的人」——与 4.31 反向，是误伤的另一半

**一句话**：**敌方 NPC 指代女主角时，代词也必须随性转**——判据是「被指的人是谁」，与说话人敌我无关。

- 地精守卫「快和我一起抓住**他**」→ 抓住**她**；卫兵队长「**他**带来了赎罪的金币」→ **她**；NPC 结巴「**他**……**他**……」→「**她**……**她**……」。
- **为什么最容易漏**：改文时会本能地认为「敌人说的话不用动」。但 4.31 管的是**脏词**，**代词不归它管**——**这是两个维度，绝不能合成一条用**。

## 4.33 保留男性的「他」——误伤第一大户

- 保留男性角色（**友善 NPC 也算**：大法师、矮人铁匠）的「他」**全部合法**，不可当残留删。实测一章内可达 **8 处**。
- **泛指不动**：「每个人都有**他**的选择」「由**他**本人承担」「向**他人**低头」「**其他**人」——「其他」读 qí tā，不是残留。
- **防误伤的做法**：把**会反复出现的保留男性 NPC 写进设定表角色处置表并标注「男 · 用他」**。**设定表条目本身就是防误改装置**——写下来就不会靠印象判。
- **按人扫描只定位候选**：可先搜角色全名、别名、裸称谓及其前后约 12 字的代词 / 称呼，逐处确认所指与说话人；12 字只是起点，不是覆盖保证。跨句指代、无姓名对话、远距回指和裸称谓仍须另查，不能以窗口零命中证明完整。
- **判性别不许凭印象**：实测同一章出过正反两例——名字看着像男性、实为**女**（查卡确认）→「他」改「她」；名字看着像男性、实为**男**（敌对位）→ 保留「他」。**两个名字看起来都像男的，查了才知道。**

## 4.34 复数「他们 / 她们」看群体性别**主体**（多数原则：不是「含不含男」）

- **全女队伍 → 必改「她们」**（实测连续 8 章每章都有，漏改第一大户之一）。
- **不要机械按「含不含男」一刀切**——那样会原样继承原著「男主 + 男队友」的男性默认底色，削弱性转后的女性群像感。
- **看群体性别主体**：女性为主体 / 唯一的男是少数或外围队友（如全女闺蜜团 + 1 名男队友）→ 用「她们」；**仅当男性是主体或对半时，才用「他们」**。
- **单指那名男队友本人，仍用「他」**（见 4.33，是另一维度，不冲突）。
- 反例对照：全女小队「**她们**在蛇谷里」改；**5 女 1 男的混合队也应改「她们」**——「**他们**只有六个人」是**原规则会错留的写法**，正是这条要修掉的。

## 4.35 性别前提句——4.9 家族的**第四类**隐性错误（长篇实测最多）

> **档位：主 L1 / L2** —— 换称呼、换动机即可；仅当"动机整个失效"（如房东只要女房客）时才升到 L3 重写场景。

> 4.9 的三类（件数品类 / 暴力接触动词 / 性暴力比喻）之外，**第四类就是本条，且它才是高频。**

**特征**：句子里**代词全对、性别标记全无**，但整句的**逻辑前提**建立在「主角是男的」上。**grep 扫不出，代词校验也扫不出——因为字面毫无问题。**

| 类型 | 例子 | 改法 |
|---|---|---|
| **亲属称谓链** | 「我是她的**哥哥**」/「这做**哥哥**大热天」/「**兄妹**两个」/「房子租给**他们兄妹**」 | 姐姐 / 姐姐 / **姐妹** / **她们姐妹** |
| **长辈的性别化称呼** | 「**小伙子**不要嘲笑」→「**小姑娘**」；「看来这**小子**很有能力」→「这**姑娘**」 | 换称呼 |
| **动机建立在性别上**（最难） | 房东「**只要女房客**」本是把男主挡在门外 → 性转后她本人就符合，动机整个失效 | **换动机，不是换词**：改成「凑不出押三付三」 |
| **调侃句的角度反转** | 「你**一个男人**还觉得吃亏啊」→「你**一个女孩子**还往外赶，也太不把我们当姐妹了吧」 | **改角度保调侃**，不是删；落脚到「姐妹」关系而非「占便宜」，更贴闺蜜打闹语境 |
| **欣赏或吸引的动机** | 「**美色**不行，用美食诱惑她」 | 女性间也可能成立；先看已定关系与玩笑功能。不成立才换成撒娇、交情等适合人物的支点，不因同性自动改 |
| **同性之间的性别说教** | 「你**一个女生家**，弄这个也不好」 | 先按 4.35e 判断残留偏见还是有意人设；不可机械改「咱们俩女生」来扩大刻板归因。若原意是实际风险，就写清当前能力或风险 |

> **判断口诀**：**问「这句话成立，需要主角是男的吗？」** 需要 → 必改；不需要 → 留。
> 这类句子的改法**不是换词而是换动机**。

## 4.35b 性别隔离框架与群像反应分配——4.35 家族的延伸

> **档位：L3**。局部删「女孩子们」、换姓名或去掉贬低旁白，不代表已经拆掉原来的男女分工。
> **来源**：用户明确认可的双向调整方向。触发包括群体词、对照词，以及无这些词却反复出现的强弱分配；本条与4.35e共同区分机械残留、有意人物偏见、不可靠视角和讽刺。

**查整场戏的分配，而非只查措辞。** 原女性总负责害怕、哭泣、退缩、依附、赞叹可爱事物，原男性性转后却包办镇定、判断、指挥、保护与看笑话，即使代词全对，也可能保留了原来的性别隔离框架。不能仅以「原著如此／保留原女性魅力／不削弱性转角色」判通过。具体人物胆小或强悍均可成立，问题在是否把两组固定成两种位置。

**落笔时依次判断：**
- **群体是谁**：「女孩子们／几个姑娘／她们／其他人」按改后场景的实际所指判断；「就连／只有／相比之下」及观看、嘲笑、评价者也要查。不能继续把原女性名单当作全女队伍中独立的女性群体。确为某几人同好或同样受惊时可保留，不把性别群体词一律替成姓名。
- **谁承担什么**：通读现场及实际读到的相邻章，追踪谁察觉风险、提出判断、行动或决策，谁求助、受照应、回应帮助。原女性在反复失去主体性、性转人物包揽优势时，修复实际反应、台词功能、互动顺序及互助关系，不能只换标签。无需每场建表或按组计数。
- **双向调整**：可让原女性有判断和行动，害怕仍能警戒、治疗、射击或提出方案；也可让性转人物受惊、窘迫、犹豫、求助、接受照应或欣赏漂亮事物。选择依据是各自经历、性格、技能、装备、任务与当场刺激，不能由女性身份直接推出反应。两边都是可选修法，非每场必须各改一处。

**边界**：保留关键情节信息、战斗机制与结果、既定能力及人物内核；可重组具体表现和局部行动，不擅改能力数值、既定长线动机或核心性格。保能力不等于每次都镇定、从不需要帮助；保原女性魅力不等于保留其系统性弱化。既有恐惧、年龄和经验差异、合理亲属依赖与人物缺点可保留；需要改变长期人设而非局部反应时，按未定核心事项确认。修复这类失效框架归B；另加恋爱／性别张力仍按C，不能借此绕限。

**成对示例**：
- ✗ 把「姑娘们躲开，队长和坦克镇定处理」改成「几个人躲开」，其余仍是原女性哭着等保护、性转角色全程嘲笑并包办。
- ✓ 怕水的医师留岸边提出接应位置并治疗，新人察觉水下异常并示警；坦克引怪后因重甲请队友拉一把，队长被浪头惊到仍及时下令。情节结果与职业能力保留，区别有具体原因。这是可能写法，不能照抄成所有队伍的固定岗位。
- ✗ 为混同两组，让所有女性一起害怕、一起爱可爱物，或规定每人必须露怯一次／两组强弱各占一半。
- ✓ 同几人欣赏首饰可以保留；其他人可参与、无兴趣或先关心收益，按各人判断，不把实用选择写成性转人物天然高于原女性的证明。

**保留与误伤**：女性间互称「美女」、自然欣赏、自信、较劲或受吸引可成立，按人物、关系、视角及4.5判断；中性事实如「双胞胎女孩」、有依据的粉丝议论不自动改。具体偏见按4.35e保其功能与后果，不强行美化所有人。不要在正文补「女性也能勇敢」等作者辩解。

**检验**：群体词检索只定位候选；通读后同时判断指称是否正确、反应分配是否仍复制原来的男女分工、改写是否有依据且无新的同质化。近邻未读则登记未查范围，不能用删词、脚本零命中或单场修好宣称全书通过。

## 4.35c 关系因果前提——4.35 家族的**第三种形态**（配角的设定反过来打自己）

> **档位：L2 / L3，无 L1** —— 病灶在因果不在词。可按既定事实修复理由或重组关系说明，不能只换称呼就收工。

> 与 4.35 的区别：4.35 讲**主角自己的动机**（房东只要女房客）；本条讲**配角与主角关系成立的理由**。与 4.35b 的区别：4.35b 拿别的女性当背景板衬托，本条根本没提别人。

**特征**：有些性格与交友说明隐含回答「**这个人为什么会跟主角做朋友**」，理由可能依赖主角为男性。性转后须重判，而非只查代词：例如「和女生玩不在一起」究竟指某群同学、一般倾向，还是绝对排斥？只有确实否定已定关系时才修复，不能把一般倾向当成没有例外的逻辑定律。

**判据一句话**：**这段设定，是不是在解释「为什么这两个人来往」？把主角换个性别，理由还成立吗？** 不成立 → 必改。

**先按 4.35e 区分有意人设、叙述立场与残留前提，保住已定关系和剧情功能。** 若原有性格、爱好、交友情况均有依据，且前文已经支持她对主角破例，可以保留这些事实并明确例外；这只是一种修法，不能凭空发明「唯独投缘」的友情。若问题本身是失效的群体性别概括，就修复该理由，或引用已经成立的共同经历、信任等关系依据，不要求保留所有原句设定再加补丁。

| 原文 | 性转后的问题 | 改后 |
|---|---|---|
| 「性格有些男孩子气，平日里喜欢动漫什么的，**和女生们玩不在一起，反而好朋友多是男生**。」（原文用以解释她与男主为何是好友） | 查这是否是绝对排斥女性的断言、局部交友事实，或有意偏见；不要脱离语境认定必然矛盾 | 前文已支持例外时，可写「跟班上那群女生玩不到一块去，好朋友多是男生，唯独和主角投缘」；否则修复失效概括，采用已有关系依据，不虚构例外 |
| 「虽然是女生，但某配角**从没把自己当女生**。在班里和主角**关系就像哥们**。」 | 「像哥们」可能只是亲近俗称，未必把女主归为男性 | 先核对已定人设与说话人口吻；成立可留，确有身份错置再换「好得穿一条裤子」等适合本书的亲近说法 |

**归类：必要因果修复属 B，不是 C。** 为修复被破坏的连接而补的内容不占 C 类额度；若另外新增关系或性别张力，该新增部分仍按 C 处理。

**grep 辅助**：`男孩子气|假小子|女生们|男生们|哥们|像兄弟` —— **仅当紧邻关系陈述**（好友 / 关系好 / 像哥们 / 玩得来）时才算命中。见词就改会大面积误伤（「这哥们」在男性之间、敌对位口中的用法合法）。

**联动检查**：这条一旦出现，几乎必然有第二处——同一段关系往往隔几章又被描述一次（实测第 2 章改完，第 7 章还有一处更直白的「关系就像哥们」）。**改完立刻 grep 该配角名 + 关系词，把后续章节的同类处登记进待处理清单。**

### 变体：分工 / 资格理由（同一病灶，从「关系」挪到「安排」）

4.35c 讲「**为什么这两个人是朋友**」，这个变体讲「**为什么这件事必须由主角来做**」。

**特征**：原文给了一整套协作安排（谁出面、谁经手、谁跑腿），而分工的依据是性别——「她是女生，不好出面办这个，所以要他去做」。

**若分工的唯一依据是主角为男性，性转后就须重判**：她自己因性别不方便，为何另一名女性方便？若原文另有资格、身份或关系依据，则先看这些事实能否继续解释安排，不自动判整套分工失效。

**判据一句话**：这件事的「由谁来做」，是不是按**性别**分的？

**改法：选择已建立、确能解释分工的理由。** 可以是信任、知识、资格、接触渠道，或已经写定的口才与性格。若本书确立她最不像经手这事的人，也可用这种反差；不凭空给主角安上正经、给同伴安上脸皮薄。先按 4.35e 判断原性别理由是否为有意人设，只有真实失效时才修复。

| 原文 | 性转后的问题 | 改后 |
|---|---|---|
| 「她之所以拉主角，还有一点：**她是女生，不好出面租给其他人**。所以要主角作为出租人。」 | 若不便的唯一原因是性别，主角性转后不能解释为何非她不可 | **仅在本书已建立同伴脸皮薄、主角是正经人时**，可用「她自己不好开口，由主角经手谁也想不到来源」的反差；否则采用已有渠道、资格或信任等事实，不补造性格 |

> **别图省事只改成「两个人都不方便」就收工。** 那等于把原文那个「为什么要拉上她」的因果整段删掉，人物关系也就没了来由。要换的是**理由**，不是**删掉理由**。

## 4.35d 以主角性别为轴的反差句与第三方理由——4.35 家族的**第四种形态**

> **档位：主 L2**（换对照项 / 换理由），极少 L3。病灶不在词，在「跟谁比、因为谁」。

两类同源问题，共同点是**句子的参照物是男性**：

| 类型 | 原文 | 性转后的问题 | 改法 |
|---|---|---|---|
| **反差型俏皮话** | 「哪有**女生**拉着**男生**买小黄书的……」 | 检查笑点究竟来自性别、人物反差还是做法；两个女生共享此兴趣本身不荒诞 | 若已定主角一向拘谨，可将调侃落到「你偏要拉我来」；若原机制已无功能可删。不能仅改「女生拉女生」便宣称修好，或凭空制造女性不应有此兴趣的刻板 |
| **第三方行为以主角性别为由** | 「她不是脸皮薄，而是知道**有男生一起**，压根就不好意思过来。」 | 主角性转后先查现场是否仍有男性，以及第三方已定的顾虑是什么，不能自动认为所有理由消失 | 若已有文本支持她因书的内容害羞，可改「知道要买的是什么东西，不好意思过来」；否则引用已有理由，或在无必要功能时删去失效解释，不新造害羞设定 |

**判据一句话**：这句的**对照项 / 理由**是「谁」？如果是「男性」→ 换成女性后重问一遍：**这个反差或理由还成立吗？**
- 不成立 → 优先用已有事实换对照项或理由，保住必要的调侃、关系或剧情功能；无必要功能时可删，不强制保留空壳笑点。
- 仍然成立 → 不必动。如「她比男生还野」「这丫头片子比男的还敢」，主角变女后照样成立。

**grep 辅助**：`哪有女生|哪有男生|女生还|男生还|一个大男人|女孩子家|有男生|有女生|不像个女的|还算个男人`

**别和 4.4b 混**：4.4b 管的是**场景支点**（她为什么要去 / 这个玩笑的驱动力），这条管的是**旁白或台词的对照项**（跟谁比、因为谁）。同一段里两者可能同时出现，分别处理。

## 4.35e 偏见与刻板印象复核：不机械继承，也不凭性转新增

> **来源**：通用一致性约束；**触发词 / 场景**：`女生都 / 女人就是 / 男人就该 / 嫉妒 / 争风 / 拆台 / 碎嘴 / 不能担当`，以及主角内心、台词或旁白中的群体性别归因。

**A1：先辨叙述层与人设。** 女性主角也可能持有偏见；不能用「主语是她」判不可能或自动删。复核是否机械继承原男主立场、是否为作者认同的旁白，还是已定人物有意保留的缺点、讽刺或不可靠视角。残留造成逻辑失效时修复；有意人设保留其功能与后果，未定则登记待确认，不擅自美化人物。

**A6：不因性转新增女性刻板。** 不凭空把嫉妒、争风、互拆台、胆小或失控归因于「她是女人」。保留原有缺点、敌意与复杂冲突，不要求所有争执都换成利益分歧，也不强迫所有对手有正当立场。具体人物可以嫉妒，不能由性转推出女性必然如此。

**候选检索不是裁决**：性别群体词附近可搜成词评价谓词或短语，如 `(女生|女人|男人|男生).{0,10}(喜欢八卦|争风吃醋|靠不住|难成大事|应该担当)`，避免用「都 / 总」等单字泛抓制造噪音。这些只是定位示例，不是女性写作词库；固定词和窗口会漏跨句、换说法、反讽与隐含前提。命中不自动改文、不直接阻断交付，须读上下文说明判断；未命中也不证明无偏见。与 4.35b 的框架检查、4.0 通读互补。

## 4.36 性暗示双关与男性化身体词（性转特有的新增风险）

> **档位：主 L1** —— 常见修复是换词；若真实问题在动机或视角，按 4.0 升档。词表只提供候选。

**双关须重读新语境**：性别与关系变化可能改变原梗的指向；同性语境不自动更性化。先核对玩笑功能、所指和 4.5 / 4.10，再决定是否修改。

| 原文 | 改后 | 为什么 |
|---|---|---|
| 「带一群人**推倒**这货」 | 若双关不合新语境，可改「当 BOSS **围殴一顿**」 | 单纯战斗术语可留，不凭「推倒」定案 |
| 闺蜜幻想「**扒光他衣服**」 | 若实为爆装备，可改「**爆了她一身装备**」 | 让动作与游戏功能一致，不因女女身份判性暗示 |
| 「大神，**求包养**啊」 | 如不合尺度或人设，可改「**求罩着**啊」 | 先辨求带玩笑、吸引或真实占有，不自动换 |
| 「单衣也遮不住的**胸肌**」 | 按已定体格可保留肌肉事实，或改衣物与肩背的受力 | 不把肌肉当男性专属，不一律换成身段 |
| 「她的**胸膛**」 | 按口吻可改「**胸口**」 | 不是身体部位禁词 |

- **身体措辞看功能与已定形象**：胸膛可按口吻改胸口；胸肌、健壮并非女性不能有的身体事实，不得为了性转抹掉肌肉或强健体格。偏男性的外貌修饰按 4.41④，身体描写边界只引用 4.5，不立「禁写胸臀」词表。
- **未成年角色去性化**：「二次元来的**小萝莉**」「**萌我一脸血**」→「小姑娘」「太可爱了」；「**控萝莉**的女生」→「**喜欢可爱风**的女生」。
  **同场景已有的穿着嫉妒或争执不因去性化一并删除**，但也不能凭性转新增女性群体归因，见 4.35e。

## 4.37 保梗原则：只切越界那一半

- **男频脏梗能保就保，只改越界的那一部分**。实例：**带性暗示的玩家 ID**——AI 曾把其中一个谐音梗整个下架；后查证该玩家是女性，**决定保留原名**。
  判据：先查名字含义、人物与玩笑功能，按 4.5 / 4.10 判断，不能以角色为女性直接判可留或必删。「腐女」等喜好设定也不因性转自动改「百合女」，只有已确认的改编方向影响其含义时才联动。
  （下架整个梗仍是过度执行。）
- 同类：「瞎了我狗日的**氪金狗眼**」→「**氪金狗眼**都瞪直了」（保住梗本身）。
- **可回退标注**：这类改动**超出性转范围**，属于主动干预，**必须显式标出「可回退」**让用户否决。
- **同一角色名字必须全书一致**：改了排行榜里的 ID，就须回查同一人的前文称呼；不是唯一需要回查的事项，语义规则变更的受影响存量按 structure.md 5.3-13 处理。

## 4.38 不解释性别——此地无银三百两

- 角色**不需要点破「我们都是姑娘」这类事实**：读者自明，写出来反而像此地无银。
  实测实例：房东「只收女客」场景，原稿让主角点破「我们都是姑娘拦不住」→ 判此地无银，定稿删掉点破，只留「全女屋邻里单纯、带妹妹放心」。
- **判据**：**性别是背景事实，不是需要角色论证的论点。**

## 4.39 去凝视必须保住功能信息

- 4.4 / 4.5 要求去物化而非去一切身体评价；**删之前先问：这句话在剧情上承担什么功能？**
  实例：「身材超好 / 只穿护住要紧部位的小皮甲 / **有很多色狼慕名而来**」→「慕名而来的玩家不少，一整天围着她什么都不干的也大有人在」。
  **色狼删了，但「围观者多 + 她脾气差会射杀」这个设定必须保住**——否则后文她射人没有铺垫。
- **母题句不删**：「别人以为她只是个哨兵队长，是族里的**美丽花瓶**」——这是 4.3 的「被低估」母题，**主角看穿他人的误判**，删掉就断了母题。**不要见「花瓶」就删。**
- **无性别指向的职业特色与辱骂先按说话人处理**：「猥琐是盗贼特色」「滚回家吃奶」「装孙子」不因性转自动删除，但**仍受 4.31 强制去糙约束**；出自主角或已性转角色的粗口须修改，保留敌对位等允许保留者的合法用法。不是职业特色就一律豁免去糙；具体换法须保住原句功能。

## 4.40 「下沉」——常驻层超限的唯一处置

> 前期的踩坑几乎都源自这一条没写好：**超限后最常见的错误动作是「逐字挤压措辞」，那是饮鸩止渴。**

- **触发**：常驻文件（规则库 / 设定表角色处置表 / 项目记忆）**超限**。**不是精确命中某个数字**——软目标只是提醒线，**连续两批超**才算真膨胀、才下沉（单次波动不触发）。
- **动作＝整条下沉**：把最情境化的条目**整条移入按需层并留索引**。
  **⛔ 禁止逐字微调措辞来凑字数**——措辞挤压既伤内容又费 token，还制造「文档必须反复维护」的错觉，下次照样超。
- **判层标准**：**改文时随手要用 → 常驻；做法 / 背景 / 论证 → 下沉。** 要问的是「这条是**规范**还是**用法**」，不是「这条长不长」。
- **失控信号**：**压缩类工具调用 ≥3 次即为失控**，无论是否达标。一次写完，复核通过就收工。
- **容器反复超限时，先收紧准入，别先调上限**：实测派生卡上限连调四次仍触顶；收准入（只留「性别＋称呼」）后一次收干。**上调是治标，收准入是治本。**
- **下沉 ≠ 删除**：移走时是**移入**（不是复制）目标层；目标层必须**真的有内容**，否则「论证见 DETAIL（`RULES-DETAIL.md`）」这种**空洞指针比没指针更糟**。
- **对称动作：往常驻层「加」内容前，先做分层自查**——加之前先判一句：这是「改文时随手要用的**判断规则**」，还是「做法 / 清单 / 示例」？前者留核心层（仍要精简）；后者**只放指针**（触发词索引 ＋ 一行指针），细则下沉按需层。
  **判据：核心层「可见」只需「指针 ＋ 关键决策」，不必内联全文——「要可见」≠「要内联」。**
  踩坑：把整份示例清单内联进核心层，等于让每章（含用不到它的章）为清单付上下文钱。

## 4.41 女性形象与人物魅力：连续阅读的具体人物

> **前置：确认形象，不自行拍板。** 开局或原文首次给出足够外形信息时，确认尚未决定的身高、体型、女性形象方向，以及是否改变原有体格。已确认的项目沿用，不反复问；未知性格标「待原文确认」。力量、耐力等功能能力默认保留；只有用户明确选择体格变化，才评估连带影响。
>
> **触发词 / 场景**：`身高 / 体格 / 相貌 / 身材 / 声线 / 神态 / 换装 / 独处 / 被注视 / 首次登场`；无固定触发词时仍靠通读。

**目标**：让读者在连续阅读中自然感知具体的女性人物。不能只去掉男性编码就结束，也不能把每句都改成女性专属。密度和落笔方式参考原著文风、角色重要性及当前节奏，不参考命中次数。

### ① 落笔前判断

先看已定形象和整段效果，再问这处描写是否能表现人物、状态或关系，是否与前文重复。**允许通用词、直接气质形容与中性动作；不做「换回男性是否违和」或「换到别处是否成立」的单句排他测试。** 头发贴颈、后背汗迹、喉咙发紧都可按语境成立，不自带合格或不合格结论。

优先把原文抽象或不合适的地方写准；需要新增时自然嵌入，不限定只能置换，也不强迫每处添加微动作。不物化的完整定义只见 4.5。

### ② 选材：七维是开放观察角度

下表帮助发现反复写发丝、视线等模板，**不是配额、词库白名单或女性特征证明**；不要求逐项完成或轮换。外貌、气质、语气、内心、关系互动也都可用，不受七个名称限制。

| 角度 | 可观察内容与适用条件 |
|---|---|
| 身体感受 | 力道、重心、冷热、酸胀；按实际动作和已定体格，不默认女性更费力、步数更多 |
| 动作方式 | 步幅、坐姿、整理装备；是否压裙摆、卷袖或垫脚须由衣物、身高与任务决定，不因女性身份强加 |
| 身体反应 | 汗、手抖、耳热、呼吸；按情绪和生理状态，不默认女性更胆小、更失控 |
| 身体形态 | 脸、整体体型、颈肩、手指等；身体边界统一见 4.5，不建立部位白名单 |
| 可见痕迹 | 汗、泥、伤、衣物褶皱；可落在身体或衣服上，无须每次显出身体轮廓 |
| 声音 | 已定声线、音量、节奏、口吻；声线也有个体与状态差异，不是性转后的固定唯一标记 |
| 他人反应 | 称呼、评价、递物、让路；须符合对方观察和世界设定，不默认所有女性都被小心照顾 |

**头发**：首次需要时写清长度样式并登记，后续按场景、视角或气氛使用。发丝并非天然补丁；近距反复拨发、贴颈可提示模板风险，不能仅因相邻章同动作而删句。也不为换维度硬添汗迹、声线或姿态。

### ③ 篇幅与节奏

**不设每章保底、总次数、单维比例或相邻章动作禁令。** 独处、与任何角色互动、做事姿态、化形或换装都可能自然流露人物魅力；纯系统说明也不需为配额补句。

恐怖、追逐、战斗等紧张场景以动作和节奏为先。可以不补，也可以让必要描写嵌进动作；撤掉削弱紧张感的装饰，不要求在后文「补回来」。同一动作的反复、同一维占比、词频只供人工复查：看是否无效重复或刻意呼应，再决定保留、删或改，不自动换词。

### ④ 红线与个人措辞偏好

- **不得因女性身份默认削弱力量、耐力、胆量、控制力或判断力**，也不凭空新增被保护需求。用户已定体格变化的，按设定修复搬运、对抗、尺度等连带因果。保住能力与人物内核，不等于锁死原男性每次镇定或独力解决的表现；有具体情境依据的受惊、犹豫、求助和接受照应可写，群像的双向调整按4.35b，不以「保能力」拒绝必要修复。
- 身体边界引用 4.5，硬护栏引用 4.10，不另加「禁写胸臀」等更严口径。
- 不统一媚化、娇气化或花瓶化；角色可利落、强悍、清冷、明快，也可以保留原有缺点和变化。不把微动作堆成每章口头禅。
- **个人外貌措辞红线保留**：女性外貌禁用「俊美 / 英俊 / 俊朗 / 棱角分明 / 硬朗 / 五官深刻」等偏男性编码词。按具体形象改用清秀、清丽、秀丽、利落、挺拔、飒爽、明丽、眉眼疏朗、线条干净等；这些只是例子，不是封闭词表。
- 男频男性化称谓按所指还原：「款爷 / 大爷」（金主义）可改「大款 / 有钱人 / 金主」；「纯爷们 / 铁血汉子」按语境改。土豪、大款、朋友等通用词、玩家 ID 中的「爷」、职业戏称「法爷」不机械删。尊称判断还见 4.6 / 4.35。
- **颜值各书自定**：不要求所有主角漂亮，不抹去已定普通、憔悴等形象；现实与游戏分层按已有设定，不凭性转凭空变美。形象变化按 4.8。

### ⑤ 登记与联动

外形写定后进设定表，注明首次交代位置，避免把齐肩、齐耳等事实记混。角色气质参考可以记在本书设定层，**不是每人必建 tick 库**，也不约束她只能有一种表情或口吻。

做「他→她 / 帅→美」等替换后核对修饰对象、主谓关系、称呼与邻句视角；真有逻辑缺口才改。女粉丝欣赏美女并无主语错误，不能为性别一致无故把「女生」改成「颜狗」。

**分类**：修复原句、能力或因果属于 B；首次设定确立属于 E（见 4.42）；**新增的关系 / 性别张力属于 C，仍受 4.3 上限约束**。不把女性描写一律排除 C，也不把所有新增句都算 C。

### ⑥ 维护

示例宜展示不同角度和处理方式，避免单一模板，不设示例数量或维度比例。4.35b / 4.35e 管性别框架与刻板归因，本条管具体形象，两者联动。语义判据改变时，对已改章节评估影响并记录已复核、已修订或待复核范围，不能默认只对未来生效；版本采用与存量流程见 structure.md 5.3-13。

## 4.42 首次提及与真正登场

> **触发词**：`首次提及 / 首次出场 / 回忆提名 / 登场 / 初登场 / 相貌 / 身材 / 长相`

**首次提及清楚交代已定性别，真正进入场景时立住形象。** 简单回忆或名单提名可以只用正确代词、称呼，不必扩写外貌介绍；出场时按角色重要性、原文文风与当前节奏，选择外貌、身形、声线或气质，不规定一组、几句或某类身体线条。

- 已在前文建立的形象不因换场景重新建立。只写「高瘦女人」是否足够，要看上下文和角色功能，不能脱离全文判女性浓度为零。
- 重要人物若仍只有性别标签、完全缺少具体印象，应结合原句或自然新增补足；允许直接形容，不强制用微动作替代。
- 战斗中的登场可把形象融入动作，不打断节奏；身体边界引用 4.5，能力保留引用 4.41④。

**例**：回忆「她说过会回来」无须加外貌；真正见面时可写「她剪着齐肩短发，说话干脆」，也可沿用已登记的高挑体格与清冷神态。选择由人物和文风决定。

本条归 **E 类首次设定确立**，不占 C 类新增张力额度；借首次出场另加暧昧或性别张力时，该新增部分仍按 C 判断。

## 4.43 服装处置：强男性编码 → 女性编码正式装

> **档位：L1** —— 病灶在「穿什么」这件物上，换同类服装即可，不动场景。

> **触发词**：`西装 / 西服 / 三件套 / 领带 / 背带 / 燕尾服 / 军装 / 制服 / 礼服 / 礼裙 / 穿着 / 服装 / 衣着`

**这是用户已定的个人换装偏好**：西装、三件套等按女性正式形象处理，不每本重问。先保留职业、场合与行动功能，再选择女士套装、女士礼装、礼服等合适款式；不是对所有女性着装的通则。

| 判定 | 处置 |
|---|---|
| **是**（强男性编码、非功能性） | 按个人偏好换**符合功能的女性正式装**：西装 / 三件套 → 礼服 / 礼裙 / 女士套装 / 晚装；领带 / 背带 / 燕尾服 → 领结 / 丝巾 / 修身礼服；硬挺军装礼服 → 女士礼装 |
| **不是**（中性 / 功能性，谁穿都合理） | **保留**，仅可按需加女性化剪裁细节（收腰 / 立领 / 袖型），**不改成裙**：白大褂 / 风衣 / 工装 / 运动服 / 普通制服 / 家居服 |

**成对反例**：
- ✗ 原「穿三件套西装的男人」只换成「穿三件套西装的女人」，没有执行已定换装偏好
- ✗ 正在抓吸血鬼的侦探改成穿礼裙——破坏场景逻辑，且把行动型角色刻板化（越过 4.41 红线）
- ✓ 庄重场合的拟人管家（原西装）→ 礼服 / 礼裙（同类正式装，换编码，场景成立）
- ✓ 白大褂 / 风衣 → 保留（中性功能装），可加收腰等剪裁细节

**红线**：
- **不得为了「女性化」把行动型角色改成裙装**——女性化 ≠ 刻板化（4.41 红线）。换装要符场景（抓人 / 战斗 / 跑动穿实用的，只在庄重 / 社交 / 仪式场合换正式女装）。
- **拟人 / 非人角色（AI 中枢、系统投影）的服装是「拟人投影」，同样按编码强度判**——不要因为「它非人」就忽略服装的性别编码。
- 换装后若后文反复提到该服装（如「那身西装」），必须**全书一致回改**（4.8），不能一处礼服一处西装。

## 4.44 感情桥段：检查动机、信息与关系功能

> **档位：L1 / L2 / L3**；**触发词**：`撮合 / 起哄 / 一对 / 不解风情 / 注孤生 / 活该单身 / 找对象 / 争风吃醋 / 护花 / 示好 / 表白 / 吃醋 / 桃花`

按开局已确认的逐书、逐人物感情方向处理（4.45），不是等遇到桥段才任意改整条线。新人物或新关系尚无足够信息时，可后续补确认；会改变整条线的未定事项须记录并确认。

**先辨功能再处理**：原桥段的动机、人物知道的信息和关系功能在性转后仍成立则保留；不成立则按最小足够粒度改写或删除。同性关系在该世界是否被默认、接受或排斥依书而定，不能套一个普遍的「没有社会默认」结论。

| 桥段 | 复核重点 |
|---|---|
| 撮合、起哄、配对猜测 | 旁人观察到什么、是什么性格、社会环境如何；可猜测、试探、猜错，不要求关系公开后才有资格 |
| 嘲单身、不解风情 | 当时实际状态、玩笑支点和关系；将来会有伴侣不使当前单身玩笑自动矛盾 |
| 争风吃醋、护花、示好 | 原动机是否成立，人物是否如此表达；不因同性配对自动降档、改动机或禁明写 |
| 配角的配对、相亲催婚等 | 性别变化是否牵动整条线及世界设定；不只换代词，也不预设全部作废 |

**删后查缺口，不等量补偿**：核对后续关系进展是否仍有来由。原有信任、欣赏、选择、亲近可以继续承担铺垫；有缺口才在合适章节补足，不要求同位置、同字数或同处数，无缺口可净删。

**成对例**：
- 初次见面的匿名路人无依据猜「她是这人的女朋友还是那人的女朋友」，又无后续功能 → 可直接删，不必同位置加晃神或暧昧。
- 熟悉两人的朋友看见长期区别对待，试探「你是不是喜欢她」→ 可以成立，即使双方未公开；问法和猜测程度须符合朋友掌握的事实。
- 旁人只因作者知道结局便断言二人已相爱 → 信息越界，按功能删改；若删去唯一关键线索导致后文突兀，再在适合的位置补信息。

与 4.3 区分：那条管新增关系 / 性别张力的必要性与 C 类额度，本条管既有桥段及其信息、因果是否成立。

## 4.45 感情进度与人物认知：按书、按人物确认

> **触发词**：同 4.44 ＋ `铺垫 / 动心 / 在意 / 注视 / 暧昧 / 公开 / 自知`

**开局确认主要感情线的方向、人物感情人设与大致进展方式，写入决策记录后沿用。** 可保留原著、慢热、单向先自知、双向暗恋、直球或用户自定；类型只是表达选择，不是必套模板。后续信息不足的新线再补确认，不替用户拍板。

**分开记录认知**：她是否察觉自己的感情、是否知道对方的感情、双方是否确认关系、旁人掌握什么事实。这些状态可以不同，不设固定依次通关流程，**自知不等于公开**。

- 心动、自认喜欢、明确吃醋、试探和表白按性格、具体触发与已定进度决定；**不设「公开前三禁」**。内敛者可以不解释，直率者可以明确自知；不强迫每人用停手、改口或找借口代替内心判断。
- 铺垫服务于进展可信度，不预设百合线比男女线更慢、更密或更多。检查「这个进展是否有来处」，从已有信任、欣赏、选择与亲近中找依据；具体细节与适合文风的概括都可承担作用。
- 同性亲近是否先被视为友情、双方是否知道对方可能喜欢女性、世界是否存在阻力，依本书设定；不默认人人都需性向觉醒或社会阻力。
- 自然欣赏、友情、恋爱吸引分开判断。旁人的猜测与调侃按 4.44；可有依据地猜错，不能无依据占有作者信息。
- 不机械按章数定频率，也不为稀缺而压低用户选择的甜度或直白程度。避免无必要预告结局与重复解释，保住当前视角和原文节奏；不禁一切感情结论。

**例**：已自知的直球人物可以想「她承认自己喜欢她，只是此时不打算说」；慢热人物也可以只注意到对方的习惯。两种都按已定人设判断，不用同一套含蓄动作替换。

## 4.10 硬护栏（不可协商）

1. 未成年角色严格排除在感情线外，全部亲情向，不做任何性化处理。
2. 不产出露骨性描写。
3. 改写他人作品公开发布可能侵权（需主动提示用户，自用练笔无碍）。
4. 形象幼态的成年角色必须在设定表显式标注「成年」，防止被误读为未成年。

> 这四条在一个项目里应有**唯一权威处**；别处只留一行指针。**唯一例外**：若某处是「只读它、不读权威文件」的，那里必须留一行指针（否则会用错口径）。修改条款时，指针指向的权威处先改。
