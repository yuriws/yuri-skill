# 执行记忆：从场景判断到正文验收

执行校准版：2026-11-19-m19。在 m18 基础上补充关系改写后的跨章因果和形象落点证据核查；依据定向复核形成，新版尚未经新会话和跨项目独立验收。本文件是本包唯一的执行记忆入口；规则以用户决定、本书现行规则和已定事实为准。本文件提供执行方法，不新增描写配额、人设或禁词表。具体小说的姓名、章号与验证结果留在项目记录。

## 一、先分清来源能证明什么

规范看现行用户决定与规则；事实看本书设定及实际正文，结合时间和载体。旧正文出现过某词，只证明过去写过，不证明符合新规则。旧批尾说“通过”，不证明旧正文正确；角色曾做某动作，也不证明本场正在做。发现冲突，查清适用范围，不以历史次数投票。

沿用原文的次数、时长、日期、数量、距离，逐项回原文核对，不凭印象，也不凭旧批尾。项目记录里写的“原文如何”同样是二手材料：一旦与原文不符，以原文为准并更正记录，**不能把“原文没有”写成自己不用它的理由**——不用它可以是本书的选择，但不能写成事实判断。

动笔前在现有批首简记本批主要人物可用的形象：姓名、现实／化身等载体、当前阶段、已查实特征及出处、连续正文已有印象。按需检索并回读，不复制完整人设或另建字典。资料暂分为“已核实且本场可用”“有旧稿记载但可靠性或适用范围待核”“尚未找到”。准备以“无可用材料”为结论时，按已有索引或首次真正出场回读连续段，核实无名描写、对白和后续姓名的承接；近邻人物的形容不能借用，没有搜到不等于不存在。未知脸型只限制脸型，不代表声线、气质等都未知；出处核到实际章节与所属人物，不凭卷名猜章号。

物件来源与当前可用性分别核实。现实中的眼镜不自动进入化身，旧章某次蒙面不证明当前全程蒙面；文件、座位、电话等一般线索不能单独锁定现实或虚拟场景。无法确认时选用不依赖争议事实的既定材料，不为保一句描写补造地点、道具或流程。

## 二、读整场，先还原冲突再改字句

先确认本项目的改造幅度及章节范围：若用户将开篇压缩、后续改为逐章保留，以相应原章正文为底稿逐段比较，保留无冲突的场景顺序、对话、内心、说明、笑点、标题和语气。识别已定性转、关系及现稿承接引起的具体冲突，只改解决它所需的层次；不得把前面压缩段的节奏、字数或“保留情节骨架”套到连续段。不能仅因信息说明较长、想增加画面感或补章末钩子就拆场重写；确需较大改动须指出原文位置、具体冲突与影响。修后回读原章与改稿并列出必要改动及原因。无性转冲突或明确校对需要的句子，连同标点、断句和口语节奏尽量保留；不要批量把长句拆成短句，也不要把主角去糙扩到其他说话者。复核对照时分别判断说话人、表达功能和改动理由，合理纠错无需机械恢复原样。

新增解释或提前揭示信息后，向后连读原文保留的提问、误会和决策：同一人物刚得到并运用了明确答案，不能不加缘由再次当成未知。改写身体、道具和能力的说法时核对实际机制与先后因果：身体部位、医疗动作、假设中的救援、正在发生的动作和已完成的结果分别表达清楚，不用含糊代称或似是而非的类比抹掉差别。个体身体状态不能自动推出所属群体的能力或资格；先还原当事人、时间和实际影响。

分别核对读者、主角和在场人物各自已知什么：主角在内心想到自己已知的能力，不等于向其他角色透露；不向对方泄露的要求不能自动删去原文内心判断。已删或拟返修的新增设定不作为后续硬约束，返修完成后以最终正文更新设定及进度。

对原样保留段和新增段采用相同尺度。先弄清：这场谁想做什么，谁判断谁，理由是什么，回应和结果如何。然后判断改词、改句还是重建比较支点；修改后连读，核对功能信息、人物内核及回应关系。已识别问题且现行规则足以判断，就完成处置；“原文自带、非本轮新增”不构成保留理由，也不构成必须交给用户的核心决策缺口。

遇到性别归因，不止核群体名词，还核“比较对象 → 判断理由 → 推出结论”。若原文把某类人的兴趣、能力或分工写成理所当然，性转后失效，就从本场真实动机重建笑点、意外或冲突。将“女人”改“人”、加“在她看来”、把旁白塞给角色，可能改变表达归属，不能自动修好归因；也不能借此新立她鄙视某群体、把所有追求都归为虚荣等长期立场。已有根据的人物偏见可以保留，判断依据是本书人物与叙事，而非女性不得有缺点。群像反应与主动权可双向调整，不齐步柔弱或齐步镇定。

多人省略与代词先还原关系：谁任什么职、谁任命谁、谁的帮手、谁受到作用、谁回应。姓名替换后再读一遍原句与改句，确认主体、受事、所有者、职务及否定范围未变。写出姓名能消歧，不能代替判断；同段的“她”可以换人，最近名词不自动取得全部动作。

去糙先判表达归属，再保表达功能。对白、内心和有依据的自由间接表达均查；无引号不自动属于旁白。主角及已性转角色的粗口按现行要求处理，旧稿曾用不豁免。例如“懵逼”按本场惊讶、发懵或措手不及的作用改写；不因发现这一问题把“这货、犯傻”等所有口语都改成客套话。男性、原女性及叙述者按各自适用规则另判。代词始终另看被指对象。

涉及训练、伤情或医疗时，先确认读者必须知道的身体部位、动作和效果；正常部位名称及合适的身体变化按 4.5 可直接说明。若原文含尺寸评判或露骨笑点，修掉失效的视角与表达，重读时仍要看清对象和功能，不以“女性在场／性转后”把身体词、自然欣赏或人物用词升级为禁令。衣物遮挡、伤疤可见范围与在场人物视角要互相对应；尊重人物在具体场景中的选择，不预设必须暴露或遮掩。

新增理由先核前提与结论是否相连：某处受伤或无法修复，不自动证明其他身体组织不存在，也不自动决定人物使用设备与否；区分初次伤情、治疗后的状态、设备能做什么与人物的选择。信息不足时，不为解释动作自造长期事实。

关系桥段连同后续叙述一起看，不能以“原文已有／玩笑／没有新增张力”代替边界判断。未成年按本书亲情、同伴或任务关系处理，不进入恋爱与性吸引线；普通相貌、衣着、神态和合宜安慰按语境。成年女性之间的欣赏、吸引、老婆等婚配用语不因女女身份自动失效，感情自知、双方确认、旁人所知分别按当章事实和既定节奏判断。

删掉原有关系动机时，连读其前后制度、处罚、对话和内心：原动机移除后，旧的调职理由、允许交往或“以后发展”的残句可能失去依据或重新暗示感情。按已定关系与正文已建立的制度重建因果，不凭空增加制度，也不把普通帮助自动判为恋爱。

压缩与并案先保住事件的因果三环：**线索—行动—结果**。删过程可以，删因果不行：结果不得凭空出现（“到了地方孩子已经在那儿”，读者不知道谁救的、凭什么救的），人物也不得未获知就说结论。压完自问一句“只读这一章，读者能不能说出这件事是怎么成的”，答不出就是压断了。

已识别的误读通常不在单个词上，而在“词—场景—因果”整条链。只把词换掉、场景因果不动，误读会原样留下。先确认读者推断与本书现行设定的具体冲突，再修正该场相关的因果并回头查同义表述；改后问一句“读者按这段会推出什么机制”，与本书设定比对，而不是核对某个词是否还出现。

关系或身份改写后，向后连读依赖旧关系的观察、误会、行为动机和计划，不以关键词清零代替因果验收。公众知道什么与实际关系分别核对；有合理误会也要让其依据和后续行为成立。涉及字源、科学或法律的新增解释，先查可靠来源；缺依据时不把联想写成确定事实。

## 三、落实具体女性形象，再判断是否充分

先按本书角色处置确定增强对象：只主动增强已性转女性（包括主角）。原著即女性者保留原有形象，不因戏份多就补外貌或记“女性浓度不足”；确有其他规则问题才作相应必要修订。原女性参与群像纠偏不使其成为形象增强对象。批首素材、落笔及批尾据此限定范围（4.41；2026-11-16用户澄清）。

批尾核对每个形象落点的出处和作用：原文已有、改写新增和仅改变代词分别记载；幼态、成年本相分别判断。战斗能力、人物性格或原有道具可支持角色塑造，但不能自动证明既定女性形象已新增或足够。按连续阅读效果评价，实际不足就据实记录并在合适场景处理，不用数量或批尾措辞充当验收。

主要性转人物分别回答：她的性格／能力／行为是否成立；连读后具体感到怎样一位女性。前者不能替代后者。形象按整场及必要连续前文判断，不要求每人每章补句，也不因独处、战斗、无旁观者或无恋爱场面停止检查。

有缺口时，从本场可用的既定相貌、整体体态、声线、神态、气质等选材，与她正在做的事共同落笔；正面形容和间接表现都可用，身体词按语境，不物化、不露骨、不扫描尺寸与部位。无需另造镜子、观看者、换装或戏剧事件。符合既定人物及现场的瞬时反应、感受、姿态与外形细节可以自然补写，未被字典逐字列举不等于新增长期人设；不得擅造长期外形、能力、关系、重要道具或影响战况的事实。

例如既定清秀的成年人物面对难懂的文件，清秀眉眼与窘意可以直接同写；比额外捏纸、推物件更能让面容进入这一刻。示例只说明取材方法，不要求所有人清秀或总写眉眼。

新增观察先核现场时间线和观察者已有信息：已看到、交谈过的人，不应无缘由再写成刚从暗处走出；不要为引出外貌替观察者凭空设定预期。多项头发、衣袖和环境痕迹堆叠不自动构成具体女性形象；连读前后对话，判断新增是否打断戏剧动作，效果不足可精简或另找自然落点，不设每章描写配额。

复核形象与身体描写时先确认当章时间及真实／变身形态，不把后续形态约束套到此前；女性肌肉、力量或有力的比喻不自动属于男性体型。负重、训练记录和能力差不能单独证明读者读到了更具体的外形；薄茧、发丝、眼神等各自有用途，也不因能列出多个身体部位就自动达标。删除不合时序的描写后，仍独立判断形象缺口是否解决。

复核性转角色时不要只查代词：追查原文笑点、恐惧、异常识别或能力机制是否依赖原有性别；性转后依据失效须局部修复并保留原有因果，不能凭空扩大能力。角色容貌或体型有显著变化时，分别核对熟人是否见过、能否认出、是否获知解释及相应动作尺度，不替角色默认知情。演习、伪装所需表现与身体真实受伤、能力是否受限分开核实；新增动作也要回看道具处理、位置和后续机制。身材矮小不自动等于不能结实；验收应结合具体体型设定及场景，不能以尺寸、眼神或身份标签替代阅读效果。

主角也在改写后的世界里：涉及女性身体、健康、训练、衣着与生活时，不只检查配角和代词，还要回查主角的既定形象、亲身经验、选择及其跨章后果；分别核实她自身与别人的情况，不因同属女性便假定体验相同，也不凭空指定生理状态。原主角性别不同导致新增的个人选择须标明依据及已定／待决状态，重要分歧交用户判断，不以某一角色的做法推成全体成员规则。

复改不能把审核意见逐条翻译成正文：先找出原场的目的、人物想要什么及对话如何推进，确认失效处，再做能解决冲突的局部改写。逐句检验：此人此刻为什么主动提这个问题，对方为什么这样回应，上一句如何引出下一句；敏感话题尤其要看双方关系和场景，不把复核问题直接塞进角色嘴里。删重复解释后仍要看是否突兀、人物口吻是否成立、情绪转折是否自然；精简或补一句“我知道”不自动等于流畅。不同身体部位、症状和个人经历分别核对，不用一种证明另一种；已在前文落实的设定不必逢相关情节再次声明。暂时遮住复核清单，连同前后原文读改稿：它是否仍像原场的人在做原场的事，读者能否跟上话题而不被迫读作者辩解？必要时比较不同的局部处理，保留最贴人物与原文的一种；缺依据就查前文或说明未解决，不凭空补经历。

补后先只连读正文，不看批首材料表或“形象已落实”的自评：具体读到怎样一位女性，哪些原句让这一印象成立？再回指实际字句，分清“查到的材料、写进去的材料、读后增加的形象”，三者不自动相等。若只能说她懂战术、沉稳、可靠、好战，按行为价值记录，不能据此放行已判断存在的形象缺口。种族与职业说明身份，不自动呈现体态；语气坚定、语调平、音量小，不自动写出声线质地；有手或脸的词也不自动补足外形。通用动作与低沉声线仍可有效，不因男性也能具有就否定；看组合后的具体印象，不做单句女性专属测试，不凑维度。

复核跨批连续效果时，既有描写的存在不是永久充分证明，也不是后续必须反复描写的理由。若本批判断“仍不足”，先结合完整场景与前文找自然落点；战斗、说明或缺少日常场景不能单独作为免检依据。若判断已充分或没有合适落点，说明具体阅读依据及未解决范围，不将“仍不足”改写成已通过，也不按维度补齐、因十章就硬加笔。

若仍薄，按原因处理：材料查证不足就查关键来源；已有可用材料未落笔就换落点或重写；已经落笔仍弱就调整呈现，不把已写过当完成。现稿已充分则保留，不能因只写一处、另一章没再展开就判不足；不要求每人每章或各维都有。开局形象不必一次定全；后续需要未定的脸型、发长／发式、体型、声线等长期特征时，先查设定及可靠前文，确属未定就主动列具体问题与候选补问用户，确认后登记并沿用，不把“开局问过”当成不能再问。已定且一致者不重问；遇无法兼容、需取舍的设定／事实冲突，列双方内容、出处、影响与方案询问，不自行选边或覆盖（4.41前置）。待确认处不算完成，可继续独立部分；不为每句瞬时描写提问，不把一种外形未知扩大成全部无法写，也不靠再加几条职业动作拖延。声称“未完成”就不同时写“够用”；“下批、单独相处时再写”不能使当前缺口自动通过。

## 四、保存后复核，再写批尾

返修完成并保存后，实际重读最终正文，再逐项回查被改动的设定、细纲、批尾和项目记忆：删除或修正因撤回旧稿而失效的台词、样本来源、章次、人物已知信息与进度。项目记忆可能在小说根目录以外，按已配置的实际路径打开核对；不以回报中写了“已同步”或只改了批尾作为同步完成的证据。引用正文时确认最终稿真的有该句，未明确交代的因果不能写成既定事实。

同一项目有多份当日或跨日记忆时，分别打开核对实际内容，合并仍有效的记录后同步；更新原有的当前进度、待办、人物状态与引用，不只在末尾追加。旧时点事实若保留，标清所属章节及已发生的后续变化；不用较旧副本覆盖较新的有效信息。最终以正文逐章独立计算字数，与设定、细纲和批尾的统计口径核对。

改名检查同时查全名、常用单字简称、称谓及代词，用上下文确认指代；保留同字的普通含义。字面相似度、字数比例和剧情节点只用于定位差异，不能证明逐句保留原文或形象已达标。

批内分段改写后，留一次以正文为对象的复核：重读原样保留段的归因、关系和口吻，也读新增段的事实、承接和形象效果。查重看表达功能与近距效果，不按部位或词频轮换；避重复不能丢失恢复形态、移动、时间推进等必要信息。战后不补成战中，未然和夸张不记为实发；数值、技能及战况因果核原文。

正文定稿保存后再取证写批尾。沿用项目字段，每个主要性转女性用“实际章号与短引文 → 行为及具体形象的分别效果 → 处理／保留与剩余”；不抄长人设、不逐段计数。区分前文事实、本轮补写和效果推断，前后章材料不能串成本批发生。候选逐项记真实处置；未核明确写未核，不能把待核写成已核实。

先说结论具体依赖哪段，再查引文是否真的支持它；湿发不证明全身瘦，拿兵器不证明某种体态。机械统计只报最终稿实际实测范围，没有重测就不写精确数字或零命中。脚本、段数、哈希分别证明对应机械事项，不能证明语义或文学效果。不同书的段落、载体与归档约定依本项目，不将历史案例升成跨题材硬限制。

返修若只修好部分，如实记部分改善。一次自主复核未发现的问题不靠重复“再仔细检查”宣布消失；有定向反馈的同章修正、新章无逐句提示、换会话与跨项目分别记录，不将其中一项通过当成全部通过。
